このツールは、ファンド報告書のテンプレート（ひな形）をパソコンの画面上で編集し、見本データを差し込んで仕上がりを確認したり、PDF を出力したりするためのものです。`{{ }}` などの特別な記号は、誤って消したり書き換えたりできないようツールが自動で保護するので、レイアウトや文言の編集に集中できます。

# 0. はじめに

## 0.1 準備するもの

- 使うのは **ブラウザ（Microsoft Edge など）だけ**です。パソコンへのインストールは不要です。
- ツールの **URL（アドレス）** と **自分のユーザー ID** を、着任時に管理者から受け取ってください。

## 0.2 このツールの大事な約束（先に読んでください）

- 編集した内容は**自動で「下書き」として保存**されます。下書きは自分だけに見えます。
- 本番のテンプレートに反映するには、**「確定保存を申請」→ 精査者の承認**という 2 段階が必要です（第 6・7 章）。承認されるまで本番は変わらないので、**うっかり本番を壊す心配はありません**。
- 自分の**権限（ロール）**によって、使える画面が変わります（下の用語表を参照）。

## 0.3 用語表（本書で使う言葉）

| 言葉 | 意味 |
|---|---|
| テンプレート | 報告書のひな形。ここに実際のデータが差し込まれて報告書になります。 |
| 差し込み値 | `{{ ○○ }}` のような「あとで実際のデータが入る場所」。誤って消したり書き換えたりできないよう、ツールが自動で保護します。 |
| 下書き | 編集途中の内容。自動保存され、自分だけに見えます。本番には影響しません。 |
| 確定保存の申請 | 「この編集内容を本番に反映してください」というお願いを出すこと。 |
| 承認 ／ 却下 | 精査者が申請の内容を確認して、本番に反映する（承認）／理由を付けて編集者へ戻す（却下）こと。 |
| プレビュー | 見本データを差し込んだ「実際の仕上がり」を画面で確認すること。 |
| コメント | 紙面のパーツに付けられる短いやり取り。状態（未対応／解決済み）を持ち、返信して会話できます。同じテンプレート（版）の中だけのもので、交付版と全体版では共有されません。 |
| 版 | 保存されたテンプレートの世代。承認されるたびに新しい版として記録されます。 |
| ロール（権限） | 編集者 = 編集と申請 ／ 精査者 = 承認・却下 ／ 管理者 = 全部 + ユーザー管理 ／ 閲覧者 = 見るだけ。 |

## 0.4 本書の読み方

はじめての方は 1 → 2 → 3 → 5 → 6 章の順に読むと、ログインから「編集して申請する」までの一連の流れがつかめます。精査者の方は 7 章、管理者の方は 10 章もご覧ください。困ったときは各章末の「うまくいかないとき」と第 11 章（FAQ）へ。ツールの画面自体が開けないときは第 12 章です。

# 1. ログインする

1. ブラウザを開きます。
2. アドレス欄にツールの URL を入力して開きます。
3. **ユーザー ID** を入力します。
4. **パスワード**を入力します（はじめての方は、管理者から受け取った**一時パスワード**です）。
5. **「ログイン」** を押します。

![ログイン画面](images/login.png)

はじめてログインしたときは、**パスワードの変更**画面が自動で表示されます。

6. **現在のパスワード**（管理者から受け取った一時パスワード）を入力します。
7. 新しいパスワードを入力します。
8. 確認のため、同じパスワードをもう一度入力します。
9. **「設定する」** を押します。

![パスワードの変更画面（初回ログイン時に自動で表示）](images/password-init.png)

> [!INFO] 一時パスワードは、管理者がアカウントを作成したときに 1 回だけ表示される文字列です。
> 管理者から直接受け取ってください。この画面を終えるまで、他の画面は使えません。

> **うまくいかないとき**: 「ログインできない」ときは、まず ID・パスワードの**全角/半角**（日本語入力がオンになっていないか）を確認してください。一時パスワードは英数字のみで、紛らわしい文字（`0` と `O`、`1` と `l`）は含まれません。何度やってもだめな場合は、管理者にパスワードのリセットを依頼してください（リセットすると新しい一時パスワードが発行されます）。ページ自体が開かない（エラー画面になる）ときは第 12 章へ。

> **パスワードを忘れたとき**: 自分では再設定できません。管理者にリセットを依頼してください。

# 2. 画面の構成

ログインすると、画面の上部に **「編集」「テンプレート作成」「比較」「承認（または申請状況）」「履歴」「結合PDF」** のタブが並びます（管理者の方は右上に「管理者」ボタンも表示されます）。

| タブ | できること |
|---|---|
| 編集 | 既存のテンプレートを探して編集する |
| テンプレート作成 | 新しいテンプレートを作る（属性から ／ 同じシリーズの別ファンドから） |
| 比較 | 2 つの版を選んで違いを見る |
| 承認 ／ 申請状況 | 申請を精査・承認する（精査者）／ 自分の申請の状況を見る（編集者） |
| 履歴 | 編集・PDF 出力・作成の記録を見る |
| 結合PDF | 複数のテンプレートをつなげて 1 つの PDF にする |

> [!INFO] 確定保存は **申請 → 承認** の 2 段階です。編集者が「確定保存を申請」し、精査者が承認したときに限り、本番テンプレートへ反映されます（第 6・7 章）。

# 3. テンプレートを探す（編集タブ）

「編集」タブでは、選択リスト（ドロップダウン）を上から順に選ぶと、テンプレートを絞り込めます。左側を選ぶと、その右側が選べるようになります。

1. **委託会社** を選びます。候補は「略称（委託会社コード）」で表示されます。
2. **ファンドコード** を選びます（「コード 名称」の形で表示されます）。
3. **基準日** を選びます。
4. 必要なら **版種** を選びます。
5. 一覧に表示されたテンプレートの行をクリックします。編集画面が開きます。

編集タブに並ぶのは、基準日の付いたテンプレートだけです。作成タブで作ったばかりのテンプレートは、作成タブの「作成中のテンプレートを開く」から開きます。

![編集タブ：属性を選んでテンプレートを検索](images/edit-tab.png)

> **うまくいかないとき**: 選択リストが選べないときは、**左側から順に**選んでいるか確認してください（左が決まると右が有効になります）。一覧が空のときは、条件に合うテンプレートがまだ無いか、絞り込みすぎです。条件をひとつ減らして試してください。

# 4. 新しく作る（テンプレート作成タブ）

1. **「テンプレート作成」** タブを開きます。
2. 委託会社・ファンド・版種を、左から順に選びます。
   - 委託会社は「略称（委託会社コード）」で表示されます。入力欄に略称や委託会社コード、ファンドコードやファンド名の一部を入力すると、候補が絞り込まれます。
   - 版種は「交付版」か「全体版」のどちらか 1 つを選びます。
   - すでにテンプレートがある会社・ファンド・版種を選ぶと、「作成済みです」という注意と **「既存のテンプレートを開く」** ボタンが表示されます。テンプレートは会社・ファンド・版種ごとに 1 つです。直すときはこのボタンで開き、編集して申請します（承認されると、そのテンプレートが上書きされます）。このとき「属性から新規作成」「既存のシリーズを元に作成」は押せません。
   - 作りかけのテンプレート（作成したが、まだ申請・承認していないもの）がある会社・ファンド・版種を選ぶと、「作成中です」という注意と **「作成中のテンプレートを開く」** ボタンが表示されます。続きはこのボタンで開きます。作り直すときは「属性から新規作成」などを押すと「作業中の内容を捨てて作り直しますか」と聞かれます。「作り直す」を押すと、作りかけの内容は捨てられて新しく作られます（コメントと修正履歴は残ります）。
3. 償還ファンドとして作るときは、「償還ファンドとして作成する」にチェックを入れます。
4. 作成方法を選びます。
   - **属性から新規作成**: 押すとテンプレートが作られ、そのまま編集画面が開きます。
   - **既存のシリーズを元に作成**: シリーズに属するファンドのときだけ表示されます。押すと、同じシリーズの別のファンド（コピー元）の一覧が出ます。元にしたいファンドの行の「作成」を押すと、編集画面が開きます。
5. コピー元の一覧で「コピー元のテンプレートがありません」と表示されているファンドは、元にできません（「作成」ボタンが押せません）。そのファンドのテンプレートを先に作るか、別のファンドを選んでください。

> [!INFO] 「申請中です。承認か却下を待ってください」と表示されたときは、同じテンプレートの作成の申請が承認待ちです。承認か却下が済んでから作り直してください。

![テンプレート作成タブ：作成済みの会社・ファンド・版種を選ぶと「既存のテンプレートを開く」が出る](images/create-tab.png)

> [!INFO] テンプレート作成タブから開いた編集画面（作成直後・「既存のテンプレートを開く」・「作成中のテンプレートを開く」）では、差し込み値（`{{ }}` の場所）が**薄い色でハイライト表示**されます。これは「あとで実データが入る場所」の目印です。編集タブ（第 3 章）から開いた編集画面では表示されず、実際の値がそのまま本文として見えます。これは故障ではなく仕様です。テンプレートには基準日が無いので、作成タブから開いた編集画面の上部に基準日は表示されません。

# 5. 編集画面の使い方

編集画面は **左・中央・右** の 3 つの区画に分かれています。

![編集画面：左にパーツ、中央にA4キャンバス、右にプロパティ](images/editor.png)

## 5.1 上部バー

左端の **←（一覧へ戻る）** を押すと、テンプレートの一覧へ戻ります（編集タブから開いたときは編集タブの一覧、テンプレート作成タブから開いたときは作成タブの一覧）。点灯しているタブをもう一度押しても、左上のツール名（RET）を押しても一覧へ戻れます（ツール名は編集タブの一覧へ戻ります）。

ファンド名と属性が表示されます。**元に戻す ／ やり直し**、**拡大 ／ 縮小（ズーム）**、**変更箇所を赤入れで表示**（取り消し線ボタン）、**自動保存の状態**、**プレビュー**ボタンがあります。

紙面を **1 ページずつ表示**するボタン（紙のアイコン）もあります。1 ページずつ表示していて、ページが 2 つ以上あるときは、**ページ送り**（「前のページ」「次のページ」とページ番号）が出ます。ここでいう「ページ」は、紙面に置いた**改ページの区切りで分けた単位**です（第 5.3 節）。1 つの区切りの中身が長く、印刷で 2 枚以上にあふれる場合も、編集画面では 1 ページと数えます。**印刷したときの本当のページ数は、プレビューで確かめてください**（第 6 章）。

自動保存の状態は保存ボタンの左隣にアイコンで表示されます（保存済みはチェック、保存中は回転する印）。アイコンにマウスを重ねると「○○ に自動保存」のように保存した時刻が読めます。画面が十分に広いときは、この文言がアイコンの右へそのまま表示されます。保存に失敗したときは画面の幅に関わらず「保存に失敗しました」と表示され、隣に **再試行** ボタンが出ます。

編集画面から別の画面へ移るときは、ツールが最後の変更まで保存してから移ります。保存できなかったときは「**変更を保存できませんでした**」という確認が出ます。**「留まる」** を押すと編集画面に残るので、上部バーの **再試行** で保存し直してください。**「離れる」** を押すと画面を移りますが、最後の変更は下書きに残りません。

## 5.2 左の区画：パーツ（部品）を足す

1. **「パーツを追加」** をオンにします。分類の選択リスト（カテゴリ → 大分類 → 中分類 → 小分類）が表示されます。
2. 分類を上から順に選びます。

![左パネル：「パーツを追加」をオンにした状態（分類カスケード）](images/editor-parts.png)

3. 小分類まで選んでパーツが 1 つに決まると、下に**そのパーツの見た目（プレビュー）**と名前・説明が表示されます。同じ名前のパーツが複数あるときだけ、分類の下に小さな選択リストが出るので 1 つ選びます。
4. 下部の **「追加」** ボタンを押します。中央の紙面に挿入されます。

また、**「編集を許可」** をオンにすると、中央の紙面を直接さわって編集できるようになります。

> **うまくいかないとき**: 「紙面をクリックしても編集できない」ときは、左の区画の **「編集を許可」がオフ**のままです。最初はオフ（誤操作防止のため閲覧のみ）なので、編集するときは最初にオンにしてください。

## 5.3 中央の区画：紙面（キャンバス）

- A4 サイズの紙面です。文字や表をクリックして選びます。
- 「編集を許可」がオンのとき、選んだブロックのまわりに**つまみ（ハンドル）**が表示されます。
  - **左右のつまみ**: 幅を変えます。
  - **上下のつまみ**: 余白を変えます。
  - **左上のグリップ（点が並んだつまみ）**: ドラッグするとパーツを並べ替えられます。
  - ドラッグ中は数値が表示されます。

![選択したブロックのまわりに出るつまみ（ハンドル）](images/editor-handles.png)

- 文字を書き換えると、**元の文字が赤い取り消し線付き**で新しい文字の前に表示されます（追加したブロックは緑、削除したブロックは橙の帯）。これは「精査者が承認するまで、何を変えたか」を紙面上で確かめるための表示で、保存・申請・PDF には入りません。承認されると自動的に消えます。
  - 取り消し線の分だけ行送りが PDF とずれます。仕上がりの流れを確認したいときは、上部バーの**取り消し線ボタン**で表示を隠してください。
  - ブロックを選ぶと、そのブロックの取り消し線は一時的に消えます（編集中は元の文字だけが見えます）。他をクリックすると戻ります。

### 改ページの区切り（「改ページ」の帯）

紙面のブロックとブロックの間に、**「改ページ」と書かれた灰色の破線の帯**が出ることがあります。これは**改ページの区切り**で、印刷ではここで次のページに移ります。帯は編集画面だけの目印で、プレビュー・PDF には出ません。

- 帯をクリックすると選べます。「編集を許可」がオンのとき、`Delete` キーで**区切りを消せます**（消すと、前後のページが 1 つにつながります）。「編集を許可」がオフのときは消せません。
- 区切りを足すときは、右の区画の「前で改ページ」「後で改ページ」を使います（第 5.4 節）。
- 帯が 2 本続いているところや、文書の先頭にある帯は、**白紙のページ**を作ります（印刷でも白紙のページが入ります）。白紙のページの帯は少し太く、「白紙のページ（区切りが続いているか、左右合わせで入るページ）」と書かれています。左右のページを合わせるために入る白紙のページ（帯の無いもの）も、1 ページずつ表示しているときは同じ文言の帯が出ます。ページを続けて表示しているときは、境目の線に「ここまで Nページ目（区切り単位。Nページ目は白紙）」と出ます。
- ページの境目には「ここまで Nページ目（区切り単位）」の線が出ます（最初から表示されています。上部バーのページ境界のボタンで隠す・表示するを切り替えられます）。この番号も区切りで分けた単位です。
- 「パーツを追加」で足したパーツは、選んでいるパーツの直後に入ります。何も選んでいないときは、いま表示しているページの終わり（次の区切りの手前）に入ります。1 ページずつ表示しているときは、足したパーツのあるページに表示が移ります。ツールが保護のためにまとめて固めた部分（テンプレート作成タブ）の中にページの区切りがあるページでは、パーツを足せません。「追加」ボタンが押せなくなり、ボタンにマウスを重ねると理由が出ます。別のページを選んでください。

## 5.4 右の区画：プロパティ・履歴・コメント

- 選んだ要素の**プロパティ（文字の大きさ・色など）を直接編集**できます。セクションは**折りたたみ**でき、必要な項目だけ開けます。
- パーツの**上へ ／ 下へ移動**、**リセット**、**削除**ができます。
- **「改ページ」**の段の **「前で改ページ」／「後で改ページ」** を押すと、選んだパーツの前（後ろ）に改ページの区切りを入れたり、取ったりできます。区切りがあるときは「ON」と表示されます。
  - 「OFF」にすると、そのパーツにいちばん近い区切りが **1 本だけ**消えます。帯が 2 本以上続いているときは、まだ区切りが残るので「ON」のままです。もう一度押すと次の 1 本が消えます。白紙のページを残したいときは、残したい本数になったところで止めてください。
  - テンプレート作成タブで、ツールが保護のためにまとめて固めた部分（中身を直接編集できない部分）を選んでいるときは、ボタンが押せません。
  - 帯（区切り）そのものを選んでいるときは、この段は表示されません。
- 下部に、そのテンプレートの編集履歴が表示されます。

> [!INFO] 編集内容は**自動で下書き保存**されます。手動で保存ボタンを押す必要はありません。本番への反映はプレビュー画面の「確定保存を申請」から行います（第 6 章）。

> **うまくいかないとき**: 間違えて編集してしまったら、上部バーの**「元に戻す」**を押してください。1 回押すごとに 1 操作ずつ戻ります。大きく戻したいときは、右の区画のパーツ「リセット」も使えます。

### コメントを書く・見る

右上の**「プロパティ」／「コメント」**の切り替えで、「コメント」を押すとこの区画がコメントの一覧に変わります。

1. 中央の紙面でコメントを付けたいパーツを選びます。
2. 一覧の上にある入力欄に本文を書いて **「追加」** を押します（`Ctrl` + `Enter` キーでも追加できます）。
3. 追加すると、選んだパーツの上に**吹き出し**が表示されます。吹き出しからは **「返信する」** で会話を続けたり、**「解決にする」** で対応済みにしたりできます。既にコメントが付いているパーツは、紙面の目印（付箋アイコン）をクリックしても開けます。

一覧の見方は次のとおりです。

- 最初は**「未対応」**のコメントだけが表示されます。解決済みのものも見たいときは、絞り込みを**「すべて」**に切り替えてください。
- 上部の検索欄に本文の一部や投稿者名を入力すると、一致するコメントだけに絞り込めます。
- 一覧の行を押すと、そのコメントが付いているパーツが選ばれ、紙面が自動でその位置まで移動します。

パーツの右上に小さな印が付きます。**琥珀色は「未対応のコメントがある」**、**灰色は「すべて解決済み」**を表します。印がなければコメントは付いていません。

> [!INFO] コメントはこのテンプレート（版）だけのものです。交付版と全体版は別々のテンプレートなので、片方に付けたコメントはもう片方には表示されません。

## 5.5 画面の上に出る黄色い警告（書式のファイル・画像・改ページ）

編集画面とプレビュー画面では、紙面の上に**黄色い帯**で警告が出ることがあります。テンプレートの書式のファイル（CSS）や画像が正しく読めないときの知らせです。警告が出ても編集・プレビュー・申請は続けられますが、直るまでは仕上がり（PDF を含む）にその書式や画像が出ません。帯は閉じられず、直るまで開くたびに表示されます。

帯には次の文言が出ます（〈 〉の部分には実際のファイル名や画像の指定が入ります）。画像の指定は 3 件まで並び、それより多いときは「ほか○件」と件数で示します。

| 帯の文言 | どんなときに出るか | どうすればよいか |
|---|---|---|
| 「CSS 〈ファイル名〉 が見つかりません。スタイルを当てずに表示しています」 | このテンプレートの書式のファイルが置かれていないとき。文字の大きさ・色・配置などの書式が付かないまま表示されます。 | 表示されたファイル名を控えて、管理者へ連絡してください。 |
| 「配信されない画像参照があります（〈画像の指定〉）。画像は `../images/<名前>` か `../images/<会社フォルダ>/<名前>` で参照してください」 | テンプレートの中の画像の指定が、ツールが画像を取り出せない書き方になっているとき。その画像は表示されません。 | 括弧の中の画像の指定を控えて、テンプレートを用意した担当者（わからなければ管理者）へ直してもらうよう連絡してください。編集画面では直せません。 |
| 「会社フォルダ名がテンプレの会社コード（〈委託会社コード〉）と違うため表示しません（〈画像の指定〉）」 | 画像が、このテンプレートとは別の委託会社のフォルダを指しているとき。他社の画像が載らないよう、その画像は画面にも PDF にも出しません。 | 上と同じく、画像の指定を控えて担当者（または管理者）へ連絡してください。 |
| 「SVG の検査で配信しない画像があります（〈画像の名前〉: 〈理由〉）。外部ツールの出力を直してください」 | SVG 形式の画像（グラフなど）の中に、安全のためツールが受け付けない書き方が含まれているとき。その画像は画面にも PDF にも出ません。〈理由〉には、ツールが受け付けなかった書き方が 1 つだけ出ます（例「許可されていない属性 name」）。 | 画像の名前と理由を控えて、その画像を作ったツールの担当者（わからなければ管理者）へ連絡してください。編集画面では直せません。 |

### 改ページ・パーツの警告（編集画面だけ）

編集画面では、改ページとパーツについて次の警告が出ることがあります（N には件数が入ります）。どれも編集・プレビュー・申請は続けられます。

| 帯の文言 | どんなときに出るか | どうすればよいか |
|---|---|---|
| 「改ページとして数えていない指定が N か所あります（ページの一番外側にない `<div class="pagebreak">` や、入れ子の要素の改ページ指定）。編集画面のページ数がプレビューとずれることがあります」 | 表や枠の中など、ツールがページの区切りとして数えない場所に改ページの指定があるとき。印刷ではそこで改ページすることがあるので、編集画面のページ数とプレビューのページ数が合わないことがあります。 | ページの切れ目はプレビューで確かめてください。直したいときは、テンプレートを用意した担当者（わからなければ管理者）へ連絡してください。 |
| 「印刷では改ページされない指定が N か所あります（要素に直接書いた page-break-before/after や break-before/after: always）。区切り（`<div class="pagebreak">`）を使ってください」 | テンプレートの中に、印刷では効かない書き方の改ページの指定があるとき。編集画面でも、そこではページを分けません。 | そこで改ページしたいときは、右の区画の「前で改ページ」「後で改ページ」で区切りを入れてください（第 5.4 節）。区切りを入れると、そのパーツの同じ側（前か後ろ）の効かない指定は自動で取り除かれます。 |
| 「書式に、区切り（.pagebreak）以外の改ページの指定があります（例: 〈場所〉）。編集画面のページ数には数えないので、本当のページ数はプレビューで確かめてください。」 | 書式のファイル（CSS）に、区切りの帯とは別の改ページの決まりが書かれているとき。印刷ではそこで改ページするので、編集画面のページ数がプレビューより少なくなることがあります。 | ページの切れ目はプレビューで確かめてください。直したいときは管理者へ連絡してください。 |
| 「テンプレの CSS に .pagebreak の改ページ指定がありません。PDF は編集画面の区切りどおりに改ページされません」 | 区切りはあるのに、書式のファイルに「区切りで改ページする」という決まりが書かれていないとき。PDF では区切りの位置で改ページしません。 | 管理者へ連絡してください。 |
| 「本文の直下に、描画すると要素になる差し込み（\|safe など）があります。承認タブとパーツの番号がずれることがあるので、パーツ（div など）の中へ入れてください。」 | テンプレート作成タブで、パーツの外（本文のいちばん外側）に、見本を差し込むと表や段落などになる差し込みがあるとき。承認タブのパーツの番号と合わなくなることがあります。 | テンプレートを用意した担当者（わからなければ管理者）へ連絡してください。 |
| 「パーツの名前（data-part-id・id・class）に差し込みがあります。このパーツのメモは承認タブで別のパーツ扱いになるので、data-part-id を固定の値で付けてください。」 | テンプレート作成タブで、パーツの名前の部分に差し込みがあるとき。そのパーツに書いたコメントが、承認タブでは別のパーツのものとして扱われます。 | テンプレートを用意した担当者（わからなければ管理者）へ連絡してください。 |
| 「古い形式のキーのメモ・修正履歴が N 件あり、どのパーツにも表示していません」 | 以前の形式で記録されたコメント・修正履歴が残っていて、どのパーツに付いていたかを決められないとき。そのコメント・修正履歴は紙面のどのパーツにも表示されません（コメントの一覧や修正履歴には「削除済みパーツ」として出ることがあります）。 | 管理者へ連絡してください。 |

# 6. プレビューを見て、申請・PDF 出力する

1. 編集画面の上部バーの **「プレビュー」** を押します。プレビュー画面に移ります。

![プレビュー画面：サンプルデータを差し込んだ実際の見た目](images/preview.png)

2. 見本データを差し込んだ実際の仕上がりが、A4 ページで表示されます。内容を確認します。

本番への反映をお願いするときは、続けて次の操作をします。

3. **「確定保存を申請」** を押します。
4. 「確定保存を申請しますか？」という確認の表示が出たら、内容を確かめて **「申請する」** を押します。これで**精査者へ申請**されます。**この時点では本番テンプレートは変更されません**。

> [!INFO] テンプレート作成タブから申請するとき、元のテンプレートより `{% if %}` などの差し込みのまとまりが減っていると、確認の表示に「**元のテンプレートより Jinja のブロック（{% if %} など）が N 個少なくなっています。意図した削除でなければ、申請せずに編集画面で確かめてください。**」と出ます。消すつもりで消したのならそのまま「申請する」を押して構いません。覚えがなければ「キャンセル」を押し、編集画面で文字を消しすぎていないか確かめてください。

> [!INFO] 同じ内容をすでに申請していて、まだ承認待ちのときは、「**同じ内容の確定保存申請が既に承認待ちです（〈日時〉に申請）。新しい申請は作りませんでした。**」と表示され、申請は増えません。ボタンを 2 回押してしまったときなどに出ます。前の申請はそのまま残っているので、承認を待ってください。

PDF がほしいときは次の操作をします。

5. **「PDF 出力」** を押します。PDF がダウンロードされ、出力履歴に記録されます。

> [!INFO] 申請後の状況は「申請状況」タブで確認できます。承認されると本番テンプレートへ反映され、却下されると理由が表示されます。

> [!WARN] プレビュー画面の上に「**このまま申請するとペアの版種へ CSS が写りません。編集画面から開き直してください**」という黄色い帯が出ることがあります。下書きのあるテンプレートのプレビュー画面を、編集画面を通さずに開いたとき（別のタブやブックマークから開いたときなど）に出ます。このまま申請しても本文の申請はできますが、承認のときに、書式の変更がペアの版種（交付版⇔全体版）へ写りません。申請する前に、編集画面からテンプレートを開き直し、上部バーの **「プレビュー」** からもう一度この画面を開いてください。帯が消えたら申請して大丈夫です。

プレビュー画面にも、編集画面と同じ書式のファイル・画像の警告が出ることがあります。文言と対処は第 5.5 節を見てください。

> **うまくいかないとき**: プレビューが真っ白のまま表示されないときは、ページの組み上げに時間がかかっているだけの場合があります。数秒待っても変わらなければ、ブラウザの再読み込み（F5 キー）をしてもう一度開いてください。それでも直らないときは管理者へ連絡してください。

# 7. 申請を確認する（精査者の方）

精査者ロールの方は、**編集タブで開いているテンプレート 1 件分**の確定保存申請を **「承認」** タブで確認し、**承認・却下**のいずれかを行います。

## 7.1 承認タブで申請を選ぶ

1. 確認したいテンプレートを、編集タブで開きます。テンプレート一覧の **「承認待ち」** バッジを押して開くこともできます。
2. **「承認」** タブを開きます。編集タブで開いているテンプレートの申請だけが表示されます。テンプレートをまだ開いていないときは、編集タブでテンプレートを開くよう案内が表示されます。
3. 上部にサマリの 3 つの箱（**承認待ち ／ 承認済み ／ 却下**）が表示されます。箱を押すと、その状態だけに一覧を絞り込めます。もう一度同じ箱を押すと絞り込みを解除し、全件表示に戻ります。

![承認タブ：申請一覧](images/reviews-list.png)

4. 申請は新しい順に積み重なって表示され、見出しを押すと開閉できます。最初は一番新しい申請が開いた状態です。**同時に開けるのは 2 件まで**で、3 件目を開くと一番古く開いていたものが自動的に閉じます。

## 7.2 精査画面の見方

開いた申請の中に「申請内容の確認」の中身が展開されます。

![精査画面：見た目で比較タブで修正前｜修正後の帳票を左右に並べて確認](images/review-diff.png)

1. 上部に、変更されたおおよその箇所数を **1 行の要約** で示します。
2. 画面だけでは分かりにくい変更があるときは、その下に **「⚠ 画面だけでは確認しきれない変更が N 件あります（開いて確認）」** という黄色い通知が出ます。開くと、次のような内容が書かれています。
   - **書式設定（文字の大きさ・色・配置などの決まり）も変更されている**: このファンドの**他の版種（全体版など）にも影響する**可能性があるため、左右の見た目比較で特に注意して確認してください。
     - 基準日の付いたテンプレートの申請では、ここに「**この CSS は同じテンプレの他の基準日にも効きます**」と表示されます。書式のファイルは基準日ごとではなく、同じテンプレートの全部の基準日で 1 つを共有しているためです。承認すると、画面で見ている基準日だけでなく、ほかの基準日の帳票の見た目も変わります。気になるときは、編集タブでほかの基準日のテンプレートも開いて確かめてから判断してください。
   - **画面では確認できない印刷用の書式が含まれている**: 心配なときは通知の中の **「PDF を開いて確認」** を押すと、修正後の PDF が別タブで開きます。
   - **一覧に表示しきれない変更がある**、または**変更が多すぎて一覧の一部が表示できない**: このときは左右の見た目比較で全ページを確認するか、変更が多い申請は編集者に分割しての再申請を依頼してください。
3. その下のタブで表示方法を切り替えられます。
   - **「見た目で比較」**（最初に開くタブ・基本はこちらで確認）
   - **「文字の変更を一覧で見る」**（文章の細かい変更を追いたいときの補助）

### 見た目で比較（基本の確認方法）

**修正前（現在の本番）｜修正後（申請された内容）** を、実際の帳票と同じ組み上げ方で左右に並べて表示します。

- **「前のページ」「次のページ」** でページをめくると、左右が連動して同じページ番号に切り替わります。
- 変更のあったページには、そのページのパーツに**黄色い印**が付きます。**「変更箇所に印を付ける」** のチェックを外すと印を消して、素の見た目のまま確認できます。
- **「次の変更箇所へ」** を押すと、変更のあったページへ順番に移動できます。
- 新規作成の申請には「修正前」がないため、**修正後の内容だけ**が 1 面で表示されます。

### 文字の変更を一覧で見る（補助）

パーツ（帳票の部品）ごとに、**変更前 ｜ 変更後** を並べて一覧表示します。変更箇所は色付きで示されます（追加 = 緑、削除 = 赤帯、語句の変更 = 下線）。最初は変更のあったパーツだけが表示され、**「変更なしも表示」** を押すと全パーツを確認できます。行の「ページN・パーツM」のページ番号は、編集画面と同じく改ページの区切りで分けた単位です（印刷したときのページ番号とは違うことがあります）。

> [!INFO] 変更が非常に大きいパーツには「この箇所は変更が大きいため、変わった文字の色付けはせず全文を並べています」と注記が付きます。この場合は変更前後の全文を読み比べてください。

## 7.3 承認・却下する

区画の下の**却下理由**の入力欄と 2 つのボタンで判断を記録します。

1. 却下するときは、却下理由の欄に理由を入力します（**必須**です）。承認するときは入力は不要です。
2. 次のいずれかを押します。
   - **「承認する」**: 申請内容が本番テンプレートへ反映され、版管理に申請者・承認者の双方が記録されます。
   - **「却下する」**: 本番テンプレートは変更されず、申請は却下として記録されます。入力した理由は申請者に表示されます。

決着した申請は「決着済み」の表示に変わります。**「承認待ち」** の箱で絞り込んでいる間は、決着した申請は一覧から外れます。**「承認済み」** または **「却下」** の箱を押して絞り込みを切り替えると一覧に戻り、決着済みの表示で確認できます。承認待ちの申請が 0 件になると、**「編集タブへ戻る」** ボタンが表示されます。

> [!INFO] 職務分掌のため（申請する人と確認する人を分けるため）、**自分が出した申請は自分では承認できません**（管理者を除く）。

> **うまくいかないとき**: 「承認する」「却下する」ボタンが見当たらないときは、①自分のロールが精査者か、②その申請が「承認待ち」状態か（承認済み・却下済みの申請は閲覧のみです）、③自分自身の申請ではないか、の 3 点を確認してください。

## 7.4 コメントを書く

各申請の区画には、右側に**コメントパネル**が並びます。見た目比較・文字の変更一覧とは別に、パーツ単位で精査者と編集者がやり取りできます。**承認・却下の判断とは独立**しており、コメントを付けても承認・却下の操作に制限は掛かりません。

1. コメントを付けたいパーツを、パネルのセレクトから選びます。
2. 内容を入力し追加します。
3. 既にあるコメントには**返信**が付けられます。対応が終わったコメントは**解決**にできます。
4. パネル上部の検索・絞り込みで、コメントを探せます。
5. コメントの行を押すと、見た目比較の該当ページへ移動します。

# 9. 複数のテンプレートを 1 つの PDF にする（結合PDFタブ）

複数のテンプレートを選んだ順につなげて、通しのページ番号が入った 1 つの PDF を出力できます。

1. **「結合PDF」** タブを開きます。
2. 編集タブと同じ要領で、委託会社・ファンド・基準日などの条件を選んで **検索** します。
3. 一覧の **「追加」** を押すと、右側の「結合する順序」リストに入ります。別の条件で検索し直して追加を繰り返せます。
4. リストの **↑ ／ ↓** ボタンで順番を入れ替えられます（上が PDF の先頭）。**×** で取り除けます。
5. **「PDF 出力」** を押します。1 件ずつ準備が進み、最後に PDF のダウンロードが始まります。

- ページ番号は、結合後の PDF 全体の通し番号が各ページの下部中央に入ります。
- 出力した PDF はツール側には保管されません（ダウンロードしたファイルは手元に残ります。履歴タブに「PDF 出力」の記録は残ります）。必要になったら同じ手順でいつでも作り直せます。

> **うまくいかないとき**: 途中で「〇件目」のエラーが出たときは、その順番のテンプレートに問題があります（削除済みなど）。リストから取り除いて再度出力してください。件数が多いと 1 分ほどかかることがあります。表示が変わらなくても、しばらくお待ちください。

# 10. 管理者の操作（ユーザー管理）

管理者の方は、右上の **「管理者」** からユーザー管理画面を開けます。

![管理者画面：ユーザーの追加と一覧](images/admin-users.png)

- ユーザーの**一覧表示**、**新規追加**（ユーザー ID・表示名・ロール）ができます。ロールには**精査者**を含みます。
- ロール変更、**有効 ／ 無効の切り替え**、**パスワードのリセット**ができます（いずれも確認の表示が出ます）。

> [!WARN] 新規追加とパスワードのリセットを行うと、**一時パスワード**が画面に表示されます。
> **この 1 回しか表示されません。** 画面を閉じる前にコピーし、本人へ直接お渡しください。
> 控え忘れたときは、もう一度リセットして新しい一時パスワードを発行します。

> [!INFO] 一時パスワードは毎回ランダムに作られ、ユーザー ID とは無関係です。本人が初回ログイン時に
> 自分のパスワードへ変更するまで、そのアカウントは他の画面を使えません。

# 12. ツールの画面が開けないとき（サーバの起動）

ふだんはブラウザで URL を開くだけで使えます。「このサイトにアクセスできません」等でページ自体が開かないときは、ツールの本体（サーバ）が動いていない可能性があります。サーバ役のパソコンを任されている方は、次の手順で起動できます（コマンド入力は不要です）。

1. サーバ役のパソコンで、エクスプローラーを開きます。
2. ツールのフォルダの中の `editor` フォルダを開きます。
3. **`start.bat` をダブルクリック**します。黒い画面（コマンド画面）が開き、準備が始まります。
4. 黒い画面に「Server : http://localhost:24680」のような案内が出るまで待ちます（初回は数分かかることがあります）。
5. ブラウザでツールの URL を開き直します。

- 黒い画面は**閉じずにそのまま**にしてください（閉じるとツールが止まります）。止めるときは黒い画面で Ctrl キーを押しながら C を押します。
- どの起動方法を使うかは環境によって決まっています。分からないときは管理者・情報システム担当の指示に従ってください（詳細は第 13 章と別冊「Editor 配布・運用手順書」）。

> **うまくいかないとき**: `start.bat` をダブルクリックしても黒い画面がすぐ消えてしまう、エラーの英文が表示される、という場合は自分で対処せず、黒い画面の表示内容を控えて管理者・情報システム担当へ連絡してください。

# 13. 開発者向け補足

本章のみ開発者・情報システム担当向けの情報です。一般のご担当者さまは読み飛ばしてください。

- **ロールの内部名**: 管理者 = `admin` ／ 精査者 = `approver` ／ 編集者 = `editor` ／ 閲覧者 = `viewer`。
- **ポート**: サーバ = `24680`、開発用画面（Vite）= `24681`。
- **起動モード**（`editor/start.bat`。引数は順不同）: 無指定 = 本番 + SQL Server 連携（要ログイン）／ `dev` = 開発 ／ `local` = 開発用のローカルデータ（DB・ログインなし）／ `lan` = 社内 LAN 公開（`local` とは併用不可。HTTPS は `scripts\setup-lan-https.bat` を事前に 1 回実行）。
- **データの保存場所**: テンプレート実体はリポジトリ外の `editor-data` フォルダ（git で版管理。確定保存 = 承認ごとに 1 コミット）。下書きと申請は同フォルダ配下で git 管理外。
- **内部構造・運用手順**: 別冊「Editor 詳細設計書」（構造・承認ワークフロー・LAN 公開の設計）と「Editor 配布・運用手順書」（オフライン構築・SQL Server セットアップ）を参照してください。
