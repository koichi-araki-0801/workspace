このツールは、ファンド報告書のテンプレート（ひな形）を画面上で編集し、サンプルデータを差し込んでプレビュー・PDF 出力するためのものです。`{{ }}` などのテンプレート記号はツールが自動で守るので、レイアウトや文言の編集に集中できます。

# 0. はじめに

## 0.1 前提

- 使うのは **ブラウザだけ**です（インストール不要）。ツールの URL・自分のユーザー ID は、着任時に管理者から受け取ってください。
- **保存の仕組み**を先に覚えてください: 編集内容は**自動保存（下書き）**され、自分だけに見えます。本番のテンプレートに反映するには **「確定保存を申請」→ 精査者の承認** が必要です（第 6・7 章）。うっかり本番を壊す心配はありません。
- 自分の**ロール（権限）**で使える画面が変わります: 編集者（editor）= 編集と申請 / 精査者（approver）= 承認・却下 / 管理者（admin）= 全部 + ユーザー管理 / 閲覧者（viewer）= 見るだけ。

## 0.2 本書の読み方

はじめての方は 1 → 2 → 3 → 5 → 6 章の順に読むと、ログインから「編集して申請する」までの一連の流れがつかめます。精査者の方は 7 章、管理者の方は 9 章もご覧ください。困ったときは 10 章（FAQ）へ。

# 1. ログインする

1. ブラウザでツールの URL を開きます。
2. **ユーザー ID** と **パスワード**を入力してログインします。

![ログイン画面](images/login.png)

3. はじめてのログインのときは、**パスワードの初期設定**画面が自動で出ます。新しいパスワードを 2 回入力し、**「設定する」** を押してください。

![パスワードの初期設定画面（初回ログイン時に自動で表示）](images/password-init.png)

> [!INFO] 初期パスワードはユーザー ID と同じです。最初のログイン後に必ず変更してください。

> **つまずきポイント**: 「ログインできない」ときは、まず ID・パスワードの**全角/半角**を確認してください。何度やってもだめな場合はパスワードが初期化されている可能性があるので、管理者に確認します（初期化後はユーザー ID がそのままパスワードです）。

# 2. 画面の構成

ログインすると上部に **「編集」「テンプレート作成」「比較」「承認（または申請状況）」「履歴」** のタブが並びます（管理者は右上に「管理者」ボタン）。

| タブ | できること |
|---|---|
| 編集 | 既存テンプレートを探して編集する |
| テンプレート作成 | 新しいテンプレートを作る（白紙 / シリーズから） |
| 比較 | 2 つの版を選んで違いを見る |
| 承認 / 申請状況 | 確定保存の申請を精査・承認する（精査者）／自分の申請状況を見る（編集者） |
| 履歴 | 編集・PDF 出力・作成の履歴を見る |

> [!INFO] 確定保存は **申請 → 承認** の 2 段階です。編集者が「確定保存を申請」し、精査者（承認者）が承認したときに限り、本番テンプレートへ反映されます（第 6・7 章）。

# 3. テンプレートを探す（編集タブ）

「編集」タブで、上から順にドロップダウンを選びます。左を選ぶと右が選べるようになります。

1. **委託会社コード** を選びます。
2. **ファンドコード** を選びます（「コード 名称」の形で表示されます）。
3. **基準日** を選びます。
4. 必要なら **版種** を選びます。
5. 一覧に出たテンプレートの行をクリックすると、編集画面が開きます。

![編集タブ：属性を選んでテンプレートを検索](images/edit-tab.png)

> **つまずきポイント**: ドロップダウンが選べないときは、**左側から順に**選んでいるか確認してください（左が決まると右が有効になります）。一覧が空のときは、条件に合うテンプレートがまだ無いか、絞り込みすぎです。

# 4. 新しく作る（テンプレート作成タブ）

1. 「テンプレート作成」タブで委託会社・ファンド・版種を選びます。
2. 作成方法を選びます。
- **属性から新規作成**：まっさらなテンプレートを作ります。
- **既存のシリーズを元に作成**：シリーズファンドのときだけ表示されます。元にするテンプレートを選んで複製します。
3. 作成すると、そのまま編集画面が開きます。

![テンプレート作成タブ：ファンドを指定して作成方法を選ぶ](images/create-tab.png)

> [!INFO] 作成直後の編集画面では、`{{ }}` の**差し込み値が薄い色でハイライト表示**されます。これは「あとで実データが入る場所」の目印で、既存テンプレートの編集画面では表示されません（実際の値がそのまま本文として見えます）。

# 5. 編集画面の使い方

編集画面は **左・中央・右** の 3 つに分かれています。

![編集画面：左にパーツ、中央にA4キャンバス、右にプロパティ](images/editor.png)

## 5.1 上部バー

ファンド名と属性が表示されます。**元に戻す / やり直し**、**拡大 / 縮小（ズーム）**、**自動保存の状態**（「○○ に自動保存」など）、**プレビュー**ボタンがあります。

## 5.2 左パネル：パーツを足す

- **「パーツを追加」** をオンにすると、分類のドロップダウン（カテゴリ → 大分類 → 中分類 → 小分類）が出ます。上から順に選ぶと下の段が選べるようになります。

![左パネル：「パーツを追加」をオンにした状態（分類カスケード）](images/editor-parts.png)

- 小分類まで選んでパーツが 1 つに決まると、下に**そのパーツの見た目（プレビュー）**と名前・説明が表示されます。同じ名前のパーツが複数あるときだけ、間に小さな選択リストが出るので 1 つ選びます。
- 下部の **「追加」** ボタンを押すと、中央の紙面に挿入されます。
- **「編集を許可」** をオンにすると、中央の紙面を直接さわって編集できるようになります。

> **つまずきポイント**: 「紙面をクリックしても編集できない」ときは、左パネルの **「編集を許可」がオフ**のままです。既定はオフ（誤操作防止のため閲覧のみ）なので、編集するときは最初にオンにしてください。

## 5.3 中央：紙面（キャンバス）

- A4 サイズの紙面です。文字や表をクリックして選びます。
- 「編集を許可」がオンのとき、選んだブロックのまわりに**つまみ（ハンドル）**が出ます。
  - **左右のつまみ**：幅を変える。
  - **上下のつまみ**：余白を変える。
  - **左上のグリップ（点が並んだつまみ）**：ドラッグでパーツを並べ替える。
  - ドラッグ中は数値が表示されます。

![選択したブロックのまわりに出るつまみ（ハンドル）](images/editor-handles.png)

## 5.4 右パネル：プロパティと履歴

- 選んだ要素の**プロパティを直接編集**できます。セクションは**折りたたみ**でき、必要な項目だけ開けます。
- パーツの**上へ / 下へ移動**、**リセット**、**削除**ができます。
- 下部にそのテンプレートの編集履歴が表示されます。

> [!INFO] 編集内容は**自動保存（下書き）**されます。確定はプレビュー画面の「確定保存を申請」で行い、精査者の承認後に反映されます（第 6・7 章）。

# 6. プレビューと確定保存の申請・PDF 出力

編集画面の上部バーの **「プレビュー」** を押すと、プレビュー画面に移ります。

![プレビュー画面：サンプルデータを差し込んだ実際の見た目](images/preview.png)

1. サンプルデータを差し込んだ実際の見た目が、A4 ページで表示されます。
2. **「確定保存を申請」** を押すと、確認のうえ編集内容が**精査者（承認者）へ申請**されます。**この時点では本番テンプレートは変更されません**。承認されると反映されます。
3. **「PDF 出力」** を押すと、PDF がダウンロードされ、出力履歴に記録されます。

> [!INFO] 申請後の反映状況は「申請状況」タブで確認できます。承認されると本番テンプレートへ反映され、却下されると理由が表示されます。

> **つまずきポイント**: プレビューが真っ白のまま表示されないときは、ページの組版に時間がかかっているだけの場合があります。数秒待っても変わらなければ、ブラウザを再読み込みしてもう一度開いてください。

# 7. 確定保存を承認する（精査者・承認者）

精査者（承認者）ロールの方は、**「承認」** タブで編集者からの確定保存申請を精査し、承認または却下します。

1. **「承認」** タブを開くと、状態（承認待ち / 承認済 / 却下）で絞り込める申請一覧が表示されます。

![承認タブ：申請一覧（承認キュー）](images/reviews-list.png)

2. 申請の **「精査する」** を押すと、**パーツ単位（行ごと）の前後プレビュー**が開きます。各行に「ページN・パーツM」の見出しと、**変更前 ｜ 変更後**が左右に並び、変更箇所が色付きで表示されます（追加＝緑、削除＝赤帯、語句の変更＝下線）。

![精査画面：パーツごとに「変更前｜変更後」を並べて確認](images/review-diff.png)

3. 既定は**変更のあったパーツのみ**表示します。「変更なしも表示」で全パーツを確認できます。
4. 内容を確認し、必要なら理由・メモを入力して **「承認する」** または **「却下」** を押します。
- **承認**：その内容が本番テンプレートへ反映され、版管理（git）に申請者・承認者の双方が記録されます。
- **却下**：本番テンプレートは変更されず、申請は却下として記録されます（理由は申請者に表示）。

> [!INFO] 職務分掌のため、**自分が出した申請は自分では承認できません**（管理者を除く）。

> **つまずきポイント**: 「承認する」ボタンが見当たらないときは、①自分のロールが精査者（approver）か、②その申請が「承認待ち」状態か、③自分自身の申請ではないか、の 3 点を確認してください。

# 8. 履歴を見る・版を比べる

- **履歴タブ**：「編集 / PDF 出力 / 作成」の 3 種類を切り替えて確認できます。実行者・期間・キーワードで絞り込めます。

![履歴タブ：編集・PDF出力・作成の履歴](images/history-tab.png)

- **比較タブ**：左右にテンプレートと版を選び、「比較」を押すと違いがハイライト表示されます。

![比較タブ：左右に版を選んで比較](images/compare-tab.png)

# 9. 管理者の操作（ユーザー管理）

管理者は右上の **「管理者」** からユーザー管理画面を開けます。

![管理者画面：ユーザーの追加と一覧](images/admin-users.png)

- ユーザーの**一覧表示**、**新規追加**（ユーザー ID・表示名・ロール）。ロールには **精査者（承認者）** を含みます。
- ロール変更、**有効 / 無効の切り替え**、**パスワードの初期化**（いずれも確認ダイアログあり）。

> [!INFO] 新規ユーザーの初期パスワードはユーザー ID です。初回ログイン時に本人が変更します。

# 10. 困ったとき（FAQ）

| こまりごと | 対処 |
|---|---|
| ログインできない | ID・パスワードの全角/半角を確認。初期化直後はユーザー ID がそのままパスワードです（第 1 章）。 |
| 突然ログイン画面に戻された | サーバの再起動などでセッションが切れています（画面に案内が出ます）。そのまま再ログインすれば続きから作業できます。編集中の内容は自動保存（下書き）に残っています。 |
| 紙面を編集できない | 左パネルの「編集を許可」をオンにしてください（第 5.2 章）。 |
| 編集したのに本番が変わらない | 編集は下書きです。プレビュー画面の「確定保存を申請」→ 精査者の承認で反映されます（第 6・7 章）。 |
| 「承認する」ボタンが出ない | 精査者（approver）ロールが必要です。また自分の申請は自分で承認できません（第 7 章）。 |
| 申請が却下された | 「申請状況」タブで却下理由を確認し、修正して再申請してください。 |
| プレビューが真っ白 | 組版待ちの場合は数秒待つ、直らなければ再読み込み（第 6 章）。それでも直らないときは管理者へ連絡してください。 |
| 間違えて編集してしまった | 上部バーの「元に戻す」（Ctrl+Z 相当）で戻せます。大きく戻したいときは右パネルのパーツ「リセット」も使えます。 |
| どこまで作業したか思い出せない | 「履歴」タブで自分の編集・PDF 出力・作成の記録を確認できます（第 8 章）。 |
