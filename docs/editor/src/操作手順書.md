このツールは、ファンド報告書のテンプレート（ひな形）をパソコンの画面上で編集し、見本データを差し込んで仕上がりを確認したり、PDF を出力したりするためのものです。`{{ }}` などの特別な記号はツールが自動で守ってくれるので、レイアウトや文言の編集に集中できます。

# 0. はじめに

## 0.1 準備するもの

- 使うのは **ブラウザ（Microsoft Edge など）だけ**です。パソコンへのインストールは不要です。
- ツールの **URL（アドレス）** と **自分のユーザー ID** を、着任時に管理者から受け取ってください。

## 0.2 このツールの大事な約束（先に読んでください）

- 編集した内容は**自動で「下書き」として保存**されます。下書きは自分だけに見えます。
- 本番のテンプレートに反映するには、**「確定保存を申請」→ 精査者の承認**という 2 段階が必要です（第 6・7 章）。承認されるまで本番は変わらないので、**うっかり本番を壊す心配はありません**。
- 自分の**権限（ロール）**によって、使える画面が変わります（下の用語表を参照）。

## 0.3 用語表（本書で使う言葉）

| 言葉 | 意味 |
|---|---|
| テンプレート | 報告書のひな形。ここに実際のデータが差し込まれて報告書になります。 |
| 差し込み値 | `{{ ○○ }}` のような「あとで実際のデータが入る場所」。ツールが自動で守ります。 |
| 下書き | 編集途中の内容。自動保存され、自分だけに見えます。本番には影響しません。 |
| 確定保存の申請 | 「この編集内容を本番に反映してください」というお願いを出すこと。 |
| 承認 ／ 却下 | 精査者が申請の内容を確認して、反映する（承認）／差し戻す（却下）こと。 |
| プレビュー | 見本データを差し込んだ「実際の仕上がり」を画面で確認すること。 |
| 版 | 保存されたテンプレートの世代。承認されるたびに新しい版として記録されます。 |
| ロール（権限） | 編集者 = 編集と申請 ／ 精査者 = 承認・却下 ／ 管理者 = 全部 + ユーザー管理 ／ 閲覧者 = 見るだけ。 |

## 0.4 本書の読み方

はじめての方は 1 → 2 → 3 → 5 → 6 章の順に読むと、ログインから「編集して申請する」までの一連の流れがつかめます。精査者の方は 7 章、管理者の方は 9 章もご覧ください。困ったときは各章末の「うまくいかないとき」と第 10 章（FAQ）へ。ツールの画面自体が開けないときは第 11 章です。

# 1. ログインする

1. ブラウザを開きます。
2. アドレス欄にツールの URL を入力して開きます。
3. **ユーザー ID** を入力します。
4. **パスワード**を入力します（はじめての方は、ユーザー ID と同じ文字列がパスワードです）。
5. **「ログイン」** を押します。

![ログイン画面](images/login.png)

はじめてログインしたときは、**パスワードの初期設定**画面が自動で表示されます。

6. 新しいパスワードを入力します。
7. 確認のため、同じパスワードをもう一度入力します。
8. **「設定する」** を押します。

![パスワードの初期設定画面（初回ログイン時に自動で表示）](images/password-init.png)

> [!INFO] 初期パスワードはユーザー ID と同じです。最初のログイン後に必ず変更してください。

> **うまくいかないとき**: 「ログインできない」ときは、まず ID・パスワードの**全角/半角**（日本語入力がオンになっていないか）を確認してください。何度やってもだめな場合はパスワードが初期化されている可能性があるので、管理者に確認します（初期化後はユーザー ID がそのままパスワードです）。ページ自体が開かない（エラー画面になる）ときは第 11 章へ。

# 2. 画面の構成

ログインすると、画面の上部に **「編集」「テンプレート作成」「比較」「承認（または申請状況）」「履歴」** のタブが並びます（管理者の方は右上に「管理者」ボタンも表示されます）。

| タブ | できること |
|---|---|
| 編集 | 既存のテンプレートを探して編集する |
| テンプレート作成 | 新しいテンプレートを作る（白紙から ／ 既存のシリーズから） |
| 比較 | 2 つの版を選んで違いを見る |
| 承認 ／ 申請状況 | 申請を精査・承認する（精査者）／ 自分の申請の状況を見る（編集者） |
| 履歴 | 編集・PDF 出力・作成の記録を見る |

> [!INFO] 確定保存は **申請 → 承認** の 2 段階です。編集者が「確定保存を申請」し、精査者が承認したときに限り、本番テンプレートへ反映されます（第 6・7 章）。

# 3. テンプレートを探す（編集タブ）

「編集」タブでは、選択リスト（ドロップダウン）を上から順に選ぶと、テンプレートを絞り込めます。左側を選ぶと、その右側が選べるようになります。

1. **委託会社コード** を選びます。
2. **ファンドコード** を選びます（「コード 名称」の形で表示されます）。
3. **基準日** を選びます。
4. 必要なら **版種** を選びます。
5. 一覧に表示されたテンプレートの行をクリックします。編集画面が開きます。

![編集タブ：属性を選んでテンプレートを検索](images/edit-tab.png)

> **うまくいかないとき**: 選択リストが選べないときは、**左側から順に**選んでいるか確認してください（左が決まると右が有効になります）。一覧が空のときは、条件に合うテンプレートがまだ無いか、絞り込みすぎです。条件をひとつ減らして試してください。

# 4. 新しく作る（テンプレート作成タブ）

1. **「テンプレート作成」** タブを開きます。
2. 委託会社・ファンド・版種を、左から順に選びます。
3. 作成方法を選びます。
   - **属性から新規作成**: まっさらなテンプレートを作ります。
   - **既存のシリーズを元に作成**: シリーズファンドのときだけ表示されます。元にするテンプレートを選んで複製します。
4. 作成ボタンを押します。そのまま編集画面が開きます。

![テンプレート作成タブ：ファンドを指定して作成方法を選ぶ](images/create-tab.png)

> [!INFO] 作成直後の編集画面では、差し込み値（`{{ }}` の場所）が**薄い色でハイライト表示**されます。これは「あとで実データが入る場所」の目印です。既存テンプレートの編集画面(第 3 章から開いた画面)では表示されず、実際の値がそのまま本文として見えます。これは故障ではなく仕様です。

# 5. 編集画面の使い方

編集画面は **左・中央・右** の 3 つの区画に分かれています。

![編集画面：左にパーツ、中央にA4キャンバス、右にプロパティ](images/editor.png)

## 5.1 上部バー

ファンド名と属性が表示されます。**元に戻す ／ やり直し**、**拡大 ／ 縮小（ズーム）**、**自動保存の状態**（「○○ に自動保存」など）、**プレビュー**ボタンがあります。

## 5.2 左の区画：パーツ（部品）を足す

1. **「パーツを追加」** をオンにします。分類の選択リスト（カテゴリ → 大分類 → 中分類 → 小分類）が表示されます。
2. 分類を上から順に選びます。

![左パネル：「パーツを追加」をオンにした状態（分類カスケード）](images/editor-parts.png)

3. 小分類まで選んでパーツが 1 つに決まると、下に**そのパーツの見た目（プレビュー）**と名前・説明が表示されます。同じ名前のパーツが複数あるときだけ、間に小さな選択リストが出るので 1 つ選びます。
4. 下部の **「追加」** ボタンを押します。中央の紙面に挿入されます。

また、**「編集を許可」** をオンにすると、中央の紙面を直接さわって編集できるようになります。

> **うまくいかないとき**: 「紙面をクリックしても編集できない」ときは、左の区画の **「編集を許可」がオフ**のままです。最初はオフ（誤操作防止のため閲覧のみ）なので、編集するときは最初にオンにしてください。

## 5.3 中央の区画：紙面（キャンバス）

- A4 サイズの紙面です。文字や表をクリックして選びます。
- 「編集を許可」がオンのとき、選んだブロックのまわりに**つまみ（ハンドル）**が表示されます。
  - **左右のつまみ**: 幅を変えます。
  - **上下のつまみ**: 余白を変えます。
  - **左上のグリップ（点が並んだつまみ）**: ドラッグするとパーツを並べ替えられます。
  - ドラッグ中は数値が表示されます。

![選択したブロックのまわりに出るつまみ（ハンドル）](images/editor-handles.png)

## 5.4 右の区画：プロパティと履歴

- 選んだ要素の**プロパティ（文字の大きさ・色など）を直接編集**できます。セクションは**折りたたみ**でき、必要な項目だけ開けます。
- パーツの**上へ ／ 下へ移動**、**リセット**、**削除**ができます。
- 下部に、そのテンプレートの編集履歴が表示されます。

> [!INFO] 編集内容は**自動で下書き保存**されます。手動で保存ボタンを押す必要はありません。本番への反映はプレビュー画面の「確定保存を申請」から行います（第 6 章）。

> **うまくいかないとき**: 間違えて編集してしまったら、上部バーの**「元に戻す」**を押してください。1 回押すごとに 1 操作ずつ戻ります。大きく戻したいときは、右の区画のパーツ「リセット」も使えます。

# 6. プレビューを見て、申請・PDF 出力する

1. 編集画面の上部バーの **「プレビュー」** を押します。プレビュー画面に移ります。

![プレビュー画面：サンプルデータを差し込んだ実際の見た目](images/preview.png)

2. 見本データを差し込んだ実際の仕上がりが、A4 ページで表示されます。内容を確認します。

本番への反映をお願いするときは、続けて次の操作をします。

3. **「確定保存を申請」** を押します。
4. 確認の表示が出たら、内容を確かめて確定します。これで**精査者へ申請**されます。**この時点では本番テンプレートは変更されません**。

PDF がほしいときは次の操作をします。

5. **「PDF 出力」** を押します。PDF がダウンロードされ、出力履歴に記録されます。

> [!INFO] 申請後の状況は「申請状況」タブで確認できます。承認されると本番テンプレートへ反映され、却下されると理由が表示されます。

> **うまくいかないとき**: プレビューが真っ白のまま表示されないときは、ページの組み上げに時間がかかっているだけの場合があります。数秒待っても変わらなければ、ブラウザの再読み込み（F5 キー）をしてもう一度開いてください。それでも直らないときは管理者へ連絡してください。

# 7. 申請を承認する（精査者の方）

精査者ロールの方は、**「承認」** タブで編集者からの確定保存申請を確認し、承認または却下します。

1. **「承認」** タブを開きます。状態（承認待ち ／ 承認済 ／ 却下）で絞り込める申請一覧が表示されます。

![承認タブ：申請一覧（承認キュー）](images/reviews-list.png)

2. 確認したい申請の **「精査する」** を押します。**パーツ単位（行ごと）の前後プレビュー**が開きます。

![精査画面：パーツごとに「変更前｜変更後」を並べて確認](images/review-diff.png)

3. 各行の「ページN・パーツM」の見出しと、左右に並んだ**変更前 ｜ 変更後**を見比べます。変更箇所は色付きで表示されます（追加 = 緑、削除 = 赤帯、語句の変更 = 下線）。
4. 必要なら「変更なしも表示」を押して、全パーツを確認します（最初は変更のあったパーツだけが表示されます）。
5. 必要なら理由・メモを入力します。
6. **「承認する」** または **「却下」** を押します。
   - **承認**: その内容が本番テンプレートへ反映され、版管理に申請者・承認者の双方が記録されます。
   - **却下**: 本番テンプレートは変更されず、申請は却下として記録されます（理由は申請者に表示されます）。

> [!INFO] 職務分掌のため、**自分が出した申請は自分では承認できません**（管理者を除く）。

> **うまくいかないとき**: 「承認する」ボタンが見当たらないときは、①自分のロールが精査者か、②その申請が「承認待ち」状態か、③自分自身の申請ではないか、の 3 点を確認してください。

# 8. 履歴を見る・版を比べる

- **履歴タブ**: 「編集 ／ PDF 出力 ／ 作成」の 3 種類を切り替えて確認できます。実行者・期間・キーワードで絞り込めます。

![履歴タブ：編集・PDF出力・作成の履歴](images/history-tab.png)

- **比較タブ**: 左右にテンプレートと版を選び、「比較」を押すと違いが色付きで表示されます。

![比較タブ：左右に版を選んで比較](images/compare-tab.png)

# 9. 管理者の操作（ユーザー管理）

管理者の方は、右上の **「管理者」** からユーザー管理画面を開けます。

![管理者画面：ユーザーの追加と一覧](images/admin-users.png)

- ユーザーの**一覧表示**、**新規追加**（ユーザー ID・表示名・ロール）ができます。ロールには**精査者**を含みます。
- ロール変更、**有効 ／ 無効の切り替え**、**パスワードの初期化**ができます（いずれも確認の表示が出ます）。

> [!INFO] 新規ユーザーの初期パスワードはユーザー ID です。初回ログイン時に本人が変更します。

# 10. 困ったとき（FAQ）

| こまりごと | 対処 |
|---|---|
| ログインできない | ID・パスワードの全角/半角を確認。初期化直後はユーザー ID がそのままパスワードです（第 1 章）。 |
| 突然ログイン画面に戻された | サーバの再起動などで接続が切れています（画面に案内が出ます）。そのまま再ログインすれば続きから作業できます。編集中の内容は下書きに残っています。 |
| 紙面を編集できない | 左の区画の「編集を許可」をオンにしてください（第 5.2 節）。 |
| 編集したのに本番が変わらない | 編集は下書きです。プレビュー画面の「確定保存を申請」→ 精査者の承認で反映されます（第 6・7 章）。 |
| 「承認する」ボタンが出ない | 精査者ロールが必要です。また自分の申請は自分で承認できません（第 7 章）。 |
| 申請が却下された | 「申請状況」タブで却下理由を確認し、修正して再申請してください。 |
| プレビューが真っ白 | 組み上げ待ちの場合は数秒待つ、直らなければ再読み込み（第 6 章）。それでも直らないときは管理者へ連絡してください。 |
| 差し込み値の色付きハイライトが出ない／出る | 新規作成中だけハイライトが出ます。既存テンプレートの編集では出ません。どちらも正常です（第 4 章）。 |
| 間違えて編集してしまった | 上部バーの「元に戻す」で 1 操作ずつ戻せます。右の区画のパーツ「リセット」も使えます（第 5 章）。 |
| どこまで作業したか思い出せない | 「履歴」タブで自分の編集・PDF 出力・作成の記録を確認できます（第 8 章）。 |
| ページ自体が開かない | ツール（サーバ）が起動していない可能性があります。第 11 章の手順で起動するか、管理者へ連絡してください。 |

# 11. ツールの画面が開けないとき（サーバの起動）

ふだんはブラウザで URL を開くだけで使えます。「このサイトにアクセスできません」等でページ自体が開かないときは、ツールの本体（サーバ）が動いていない可能性があります。サーバ役のパソコンを任されている方は、次の手順で起動できます（コマンド入力は不要です）。

1. サーバ役のパソコンで、エクスプローラーを開きます。
2. ツールのフォルダの中の `editor` フォルダを開きます。
3. **`start.bat` をダブルクリック**します。黒い画面（コマンド画面）が開き、準備が始まります。
4. 黒い画面に「Server : http://localhost:24680」のような案内が出るまで待ちます（初回は数分かかることがあります）。
5. ブラウザでツールの URL を開き直します。

- 黒い画面は**閉じずにそのまま**にしてください（閉じるとツールが止まります）。止めるときは黒い画面で Ctrl キーを押しながら C を押します。
- どの起動方法（引数）を使うかは環境によって決まっています。分からないときは管理者・情報システム担当の指示に従ってください（詳細は第 12 章と別冊「Editor 配布・運用手順書」）。

> **うまくいかないとき**: `start.bat` をダブルクリックしても黒い画面がすぐ消えてしまう、エラーの英文が表示される、という場合は自分で対処せず、黒い画面の表示内容を控えて管理者・情報システム担当へ連絡してください。

# 12. 開発者向け補足

本章のみ開発者・情報システム担当向けの情報です。一般のご担当者さまは読み飛ばしてください。

- **ロールの内部名**: 管理者 = `admin` ／ 精査者 = `approver` ／ 編集者 = `editor` ／ 閲覧者 = `viewer`。
- **ポート**: サーバ = `24680`、開発用画面（Vite）= `24681`。
- **起動モード**（`editor/start.bat`。引数は順不同）: 無指定 = 本番 + ローカルデータ ／ `dev` = 開発 ／ `rest` = SQL Server 連携（要ログイン）／ `rest lan` = 社内 LAN 公開（HTTPS は `scripts\setup-lan-https.bat` を事前に 1 回実行）。
- **データの保存場所**: テンプレート実体はリポジトリ外の `editor-data` フォルダ（git で版管理。確定保存 = 承認ごとに 1 コミット）。下書きと申請は同フォルダ配下で git 管理外。
- **内部構造・運用手順**: 別冊「Editor 詳細設計書」（構造・承認ワークフロー・LAN 公開の設計）と「Editor 配布・運用手順書」（オフライン構築・SQL Server セットアップ）を参照してください。
