本書は Editor を運用機へ構築・運用するための手順を、情報システム担当向けにまとめる。内部構造は別冊「Editor 詳細設計書」を参照。フェーズ1（ローカル）/ フェーズ2（REST + SQL Server）の両方を扱う。

# 1. 構成方針

- **PDF 生成はサーバ側に集約**（運用機 1 台）。ブラウザは社内 Windows の Microsoft Edge を使う（Chromium 同梱なし）。
- **依存はオフライン調達**: pnpm オフラインストア（`.pnpm-store/`）を tar.gz で持ち込み、運用機で復元する。
- フォントは @fontsource でローカル同梱（Google Fonts CDN 非依存）。
- 前提: パッケージマネージャ `pnpm@11.8.0+`、Node `>=24`。

> [!WARN] 調達機と運用機は **Windows x64・Node 24 で一致**させること（msnodesqlv8 等のネイティブバイナリが必要）。

# 2. オフライン調達・展開

1. **調達**: ネット接続のある機で依存を取得し、バンドル tar.gz（`.pnpm-store/`・`pnpm.tgz`・`ms-playwright/` 同梱）を生成する。
2. **持ち込み・展開**: 運用機で `offline/setup-offline.bat` を実行し、展開〜`pnpm install --offline`〜`pnpm build` まで完走させる（ネイティブバイナリの追加取得が走らないこと）。
3. **検証**: 5 章のチェックリストを実施する。

# 3. appconfig.json 設定

設定は **既定値 < `appconfig.json` < 環境変数** の優先順位で解決する。雛形は `appconfig.example.json`。

| キー | 内容 | 環境変数 |
|---|---|---|
| `port` | サーバ待受ポート（既定 24680） | `PORT` |
| `paths.templatesDir` | テンプレ .html 置き場 | `TEMPLATES_DIR` |
| `paths.cssDir` | ファンド毎 CSS | `CSS_DIR` |
| `paths.tmpDir` | 一時ファイル | `TMP_DIR` |
| `paths.logDir` | ログ出力先 | `LOG_DIR` |
| `paths.webDist` | ビルド済みフロント（`web/dist`） | `WEB_DIR` |
| `python.bin` | Python 実行ファイル | `PYTHON_BIN` |
| `python.script` | テンプレ生成スクリプト | `PY_GENERATE_SCRIPT` |
| `python.timeoutMs` | 生成タイムアウト | `PY_TIMEOUT_MS` |
| `pdf.executableBrowser` | PDF 用ブラウザ（空=Edge 自動検出） | `VIVLIOSTYLE_EXECUTABLE_BROWSER` |
| `logging.level` | ログレベル（既定 info） | `LOG_LEVEL` |
| `logging.pretty` | Pretty 整形（本番は false） | `LOG_PRETTY` |

# 4. SQL Server セットアップ（フェーズ2）

ターゲットは **SQL Server 2012**、DB `usrap`、既存スキーマ `ug01`、テーブル接頭辞 `Rep1_運報自動化_Editor_`。DB アクセスは 6 ゲートウェイ sproc（第1引数 `@操作` で分岐）を通す（設計書 §8.3 参照）。

DDL/sproc/seed は `server/db/` に置く。

```
ddl/    01_テーブル.sql 02_索引.sql 03_制約.sql
sproc/  <6種類>.sql（DROP + CREATE）
seed/   管理ユーザー.sql / パーツカタログ.sql / サンプルデータ.sql
```

> [!WARN] 全 SQL ファイルは **UTF-8 BOM 保存**（日本語識別子 + sqlcmd の cp932 対策）。SQL Server 2012 互換のため `CREATE OR ALTER` / `OPENJSON` / `FOR JSON` / `STRING_AGG` は不使用。

適用手順:

```
# 1) seed SQL を生成（管理ユーザーのパスワードハッシュ + seed）
corepack pnpm --filter server exec tsx scripts/hash-password.ts admin "<パスワード>" 管理者 admin
corepack pnpm --filter server exec tsx scripts/gen-seed.ts

# 2) 適用（Windows 統合認証）
powershell -ExecutionPolicy Bypass -File server\db\apply.ps1 -Server <host\instance>
```

`apply.ps1` が ddl → sproc → seed の順に適用する。

# 5. 起動（モード別）

`start.bat` のモードで起動する。

| 用途 | コマンド |
|---|---|
| 開発（Express:24680 + Vite:24681） | `pnpm dev` または `start.bat dev` |
| 本番（ビルド後 :24680 単体） | `pnpm build` 後 `pnpm --filter server run start`、または `start.bat prod` |
| REST モード（開発） | `start.bat dev rest` |
| REST モード（本番） | `start.bat prod rest` |
| LAN 公開（本番 + REST + HTTPS） | `start.bat rest lan`（事前に `scripts\setup-lan-https.bat` と `scripts\setup-lan-firewall.bat` を各 1 回実行。詳細は editor/README.md「LAN 公開」節） |

REST モードは `VITE_API_MODE=rest` / `AUTH_REQUIRED=true` / `AUDIT_DB=true` を有効化し、Repository を REST 実装に差し替えて SQL Server に接続する。

> [!WARN] REST モードには msnodesqlv8 が必要。オフラインバンドルに含まれていない場合は、Windows x64・Node 24 一致のうえ再バンドルすること。

# 6. オフライン検証チェックリスト

1. **調達**: バンドル tar.gz（`.pnpm-store/`・`pnpm.tgz`・`ms-playwright/` 同梱）が生成される。
2. **遮断**: ネット遮断で `offline/setup-offline.bat` の展開〜`pnpm build` が完走、ネイティブ取得が走らない。
3. **起動**: `GET /api/health` → `{ok:true}`、ブラウザで SPA 表示、DevTools で外部通信なし。
4. **PDF（最重要）**: `POST /api/build` で PDF 生成成功、Edge 自動検出が機能、MathJax 失敗でストール/失敗しない。
5. **生成/保存**: `POST /api/generate`・`PUT /api/templates/:id/draft`・`POST /api/templates/:id/confirm` が成功。
6. **エディタ UI**: GrapesJS のアイコン/スタイルに欠けがない。
7. **回帰**: `pnpm typecheck`・`pnpm check:ci` が通る（typecheck は `@editor/shared` 先行ビルドが前提）。

# 7. 監査ログ

- 監査ログは `logs/audit.log`（`logging.level` / `logging.pretty` で制御）。フェーズ2 では `AUDIT_DB=true` で監査ログ sproc にも記録する。
- ログレベル既定は `info`（`LOG_LEVEL` で上書き可）。本番は `NODE_ENV=production` で Pretty 無効（`LOG_PRETTY` で上書き可）。

# 8. SQL エラーと HTTP の対応

`server/src/db/sproc.ts` が SQL エラーを HTTP へマップする。運用時の切り分けに使う。

| SQL エラー | 種別 | HTTP |
|---|---|---|
| `THROW 50404` | not_found | 404 |
| `THROW 50409` / 一意制約 2627・2601 | conflict | 409 |
| `THROW 50000`（必須パラメタ不足等） | validation | 400 |
| その他 | unexpected | 500 |
