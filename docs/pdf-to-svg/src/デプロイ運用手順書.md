本書は PdfToSvg を社内端末へ配布・運用するための手順を、情報システム担当向けにまとめたものである。ツールの内部構造は別冊「PdfToSvg 詳細設計書」を参照。

# 1. 配布方針

PdfToSvg は**インストーラを持たない**。PyInstaller の onedir 形式でビルドした `dist/PdfToSvg/` フォルダを**そのままコピー**して配る、ポータブル配布方式を取る。

- レジストリを使わない／管理者権限不要。ユーザー権限のまま動く。
- 辞書・設定は exe と同じ場所の `data/` に置く（C ドライブや %APPDATA% に非依存）。フォルダごと移動・複製できる。
- UI は OS 標準の Microsoft Edge をアプリモードで開くため、Chromium ランタイムは同梱しない（配布物 ~50MB）。

# 2. ビルド手順

ビルドはネットワークのある開発端末で行う。リポジトリ直下の `build.bat` をダブルクリックするだけでよい。

1. `build.bat` が隔離 venv（`.venv-build`）を作成し、ビルドに必要な依存のみインストールする。
2. `pyinstaller packaging/pdftosvg.spec --clean --noconfirm` で onedir exe を生成する。
3. 成果物 `dist/PdfToSvg/`（`PdfToSvg.exe` + `_internal` + `resources` + `fonts`）が出力される。

コマンドで実行する場合:

```
python -m pip install pyinstaller
pyinstaller packaging/pdftosvg.spec --noconfirm
```

`packaging/pdftosvg.spec` は `PySide6` / `shiboken6` を除外し、`fonts/` と `resources/` を datas として同梱する。`data/` は初回起動時に exe 隣へ自動生成される。

# 3. ビルド後の確認（チェックリスト）

配布前に、ビルド端末で次を確認する。

- `dist/PdfToSvg/` に `QtWebEngineProcess.exe` / `*.pak` / `locales/` / ICU / Qt DLL が**無い**こと（従来比 ~120〜150MB 縮小）。
- `fitz`（PyMuPDF）のネイティブ DLL が `_internal` に揃っていること。
- **ネットワーク遮断下でも起動・書き出しができる**こと（外部通信に依存しないことの確認）。
- `PdfToSvg.exe` をダブルクリックして Edge のアプリ窓が開き、4 ステップを一巡して SVG を書き出せること。

> [!INFO] Edge は Windows 10 / 11 に標準搭載のため別途配布は不要。万一 Edge が無い端末では起動できないので、対象端末に Edge があることを事前に確認する。

# 4. 配布・展開

1. `dist/PdfToSvg/` フォルダを ZIP などにまとめ、共有フォルダや配布メディアで対象端末へ渡す。
2. 受け取った端末では任意の場所（デスクトップ・業務フォルダ等）へ展開する。インストール操作は不要。
3. `PdfToSvg.exe`（または開発用に `run.bat`）をダブルクリックして起動する。

# 5. 辞書の配布・共有

用語辞書は端末ごとに `data/dictionary.json` として持つ。共通の辞書を配るには次のいずれか。

- **ファイル配布**: マスタ辞書 `dictionary.json` を各端末の `data/` へ上書きコピーする。
- **UI 経由**: 配布元で「辞書」タブの **「⬇ JSON 書き出し」**、受け取り側で **「⬆ JSON 読み込み」** を使う（操作手順書 8 章参照）。

辞書は NFKC 正規化で全角/半角差を吸収する。フォーマットは次の通り（人手編集可）。

```
[
  {"source": "元の語", "target": "置換後の語", "enabled": true},
  {"source": "Old Header", "target": "New Header", "enabled": false}
]
```

# 6. 運用・トラブル対応

| 事象 | 対処 |
|---|---|
| アプリ窓が開かない | 数十秒待って再度起動。`data/logs/startup.log` に起動診断が出るので確認（exe は console 非表示のため stderr の代替）。 |
| VDI/リモートデスクトップでアプリ窓がクラッシュする | 本ビルドは端末標準の「管理された」既定 Edge と同じ構成で開き（特殊フラグ無し）、ファイルの開く/保存もネイティブダイアログを使わない（従来型ダイアログ＋ダウンロード）ため VDI でも安定するよう対策済み。なお落ちる場合は `data/logs/startup.log` と `data/logs/edge.log`（Edge 側）を情報システム担当へ。 |
| PDF が選べない / ダイアログで固まる | エクスプローラーからウィンドウへ PDF を**ドラッグ＆ドロップ**でも読み込める。 |
| 保存先が選べない | 仕様（VDI 安定化のため）。保存はブラウザのダウンロードフォルダへ出力される。 |
| 端末に Edge が無い | Edge を導入（Win10/11 は標準搭載）。アプリモード表示に Edge が必須。 |
| 辞書が反映されない | 「全ファイルに再適用」を実行。本文も対象にするには「ヘッダのみに適用」を外す。 |
| 別端末へ丸ごと移したい | フォルダごとコピーすれば `data/`（辞書・設定）も一緒に移る。 |

終了は窓を閉じた時の `/quit` ビーコン、または `/ping` 途絶を見張る idle watchdog（60 秒）で行われる。黒いコンソール窓（ソース起動時）は閉じないこと。

# 7. ライセンス運用上の注意

> [!WARN] 本ツールは **PyMuPDF (AGPL)** に依存するため、**社内 / 身内限定の配布**を前提とする。外部・商用配布が必要になった場合は、抽出部 `engine/pdf_engine.py` を BSD ライセンスの **pypdfium2** 等へ差し替えるか、Artifex の商用ライセンスを取得すること。

同梱フォント（BIZ UDPゴシック / Noto Serif JP）はいずれも **SIL OFL 1.1**（`fonts/OFL-*.txt`）で再配布可。SVG 出力時は使用グリフのみを WOFF2 サブセットで埋め込むため、ライセンス表記を保ったまま軽量に配布できる。
