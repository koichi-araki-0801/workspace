SVG ラベル位置エディタ 操作手順書

円グラフの文字と引出線を手直しするツール ／ ご担当者さま向け

v3.0最終改訂 2026-07-23

このツールは、円グラフの画像ファイル（SVG ファイル）を開いて、文字（ラベル）の位置をマウスで 少しだけ動かして直し、直した結果を新しいファイルとして保存するためのものです。

  • 使うのは `LabelEditor.exe` という 1 つのファイルだけです。ダブルクリックで起動します。
  • インストール作業は不要です。黒い画面（コマンド入力）も一切使いません。
  • 元のファイルは書き換わりません。直した結果は別ファイルとして保存されるので、失敗しても

元に戻せます。安心して操作してください。

1. はじめに — 用語の説明

本書に出てくる言葉を先にまとめます。わからない言葉が出てきたら、ここに戻ってください。

言葉意味
SVG ファイル円グラフの画像ファイルです。ファイル名の最後が「.svg」になっています。
ラベルグラフに書いてある文字のことです（例:「国内株式 25.0%」）。
引出線円グラフとラベルを結ぶ細い線のことです。
ハンドルラベルを選ぶと出てくる小さな丸い点です。マウスでつまんで動かせます。
ドラッグマウスのボタンを押したまま動かして、離す操作です。
長体（ちょうたい）文字を横方向にだけ少し細くして、幅を詰める機能です。
ダウンロードフォルダパソコンの「ダウンロード」という名前のフォルダです。保存したファイルはここに入ります。

2. 作業の流れ

画面の上に「1 ファイルを開く → 2 位置を調整 → 3 SVGを保存」という 3 つのステップが表示されます。 この順番に進むだけで作業が終わります。

ステップやること本書の章
1 ファイルを開く直したい SVG ファイルを選びます3 章
2 位置を調整文字をマウスで動かして直します4 章
3 SVGを保存直した結果を保存します5 章

2.1 画面の見方（編集中の画面全体）

場所名前役割
いちばん上アプリバー開いているファイル名と、「元に戻す」「やり直し」ボタン
上ステップバー今どのステップにいるかの表示。クリックで行き来できます

3. ステップ1: ファイルを開く

  1. LabelEditor.exe をダブルクリックします。
  2. 少し待つと「SVGファイルを開く」という画面が開きます。
  1. 画面中央の 「ファイルを選択…」 ボタンをクリックします。
  2. ファイルを選ぶ画面が出るので、直したい SVG ファイルをクリックします

（Ctrl キーを押しながらクリックすると、複数まとめて選べます）。

  1. 「開く」 をクリックします。
  2. グラフが表示され、自動的にステップ 2（位置を調整）へ進みます。
TIPファイルを画面の点線の枠の中へドラッグ＆ドロップしても開けます（エクスプローラー からファイルをつまんで、枠の上で離す）。

4. ステップ2: 文字の位置を直す

4.1 文字を動かす（基本の操作）

  1. 動かしたい文字の上にマウスを合わせます。
  2. マウスのボタンを押したまま、動かしたい方向へマウスを動かします。
  3. ちょうどよい位置でボタンを離します。

これだけで文字が動きます。引出線は文字に自動でついてきますので、気にしなくて大丈夫です。

INFO文字を円の外へ出すと引出線が自動で付き、円の中へ戻すと自動で消えます。

4.2 引出線を細かく直す

文字をクリックして選ぶと、引出線の上に小さな丸い点（ハンドル）が出ます。

色名前操作
🟢 緑端点（文字側の先っぽ）ドラッグで動かせます
🔵 青曲点（線の折れ曲がる所）ドラッグで動かせます
🟠 橙アンカー（円にくっつく根元）動かせません（グラフの正しい位置に固定されています）
INFO一度でも手でハンドルを動かした引出線は、それ以降は自動で付いたり消えたりしません （あなたの調整がそのまま守られます）。

4.3 右側のパネルで見た目を整える

文字をクリックして選ぶと、画面右側の「選択中のラベル」パネルで次の切り替えができます。

  • 引出線: 「表示」「非表示」ボタンで、引出線を出したり消したりします。
  • 曲げ点: 「あり」で線が L 字に折れ、「なし」でまっすぐな線になります。
  • 文字色: 「黒」「白」を切り替えます。
  • 行数: 「1行」で名前とパーセントが横一列に、「2行」で上下二段になります。
  • 長体（横圧縮）: つまみを左へ動かすと、文字が横に細くなって幅が詰まります

（100%〜70%）。文字の高さとパーセント部分は変わりません。

4.4 失敗したとき・やり直したいとき

  • 1 つ前に戻す: キーボードの Ctrl キーを押しながら Z キーを押します

（画面いちばん上の ↩ ボタンでも同じです）。

  • 戻しすぎたのをやり直す: Ctrl キーを押しながら Y キーを押します（↪ ボタンでも可）。
  • 選んだ文字 1 つだけを最初に戻す: 右パネルのいちばん下の 「このラベルをリセット」 を

クリックします。

  • ファイル全体を最初に戻す: 画面左下の 「このファイルをリセット」 をクリックします。

確認の画面が出るので「OK」をクリックします。

4.5 キーボードでの操作一覧

キー動作
矢印キー（←↑↓→）選んだ文字を少しずつ（1px）動かす
Shift + 矢印キー大きめに（10px）動かす
Ctrl + Z / Ctrl + Y元に戻す / やり直し
Ctrl + Oファイルを開く
Ctrl + S保存する（ステップ 3 と同じ）
Escape文字の選択を解除する

5. ステップ3: 保存する

  1. 画面右下の 「次へ」 をクリックしてステップ 3 へ進みます。
  2. 「保存する」 ボタンをクリックします。
  1. 直した結果が、パソコンのダウンロードフォルダに新しいファイルとして保存されます。
  2. 保存されたファイルは、エクスプローラーで「ダウンロード」フォルダを開くと見つかります。

そこから必要な場所（共有フォルダなど）へ移動してください。

INFO保存先を選ぶ画面は出ません（ダウンロードフォルダに固定です）。これはリモート デスクトップ環境でも安定して動かすための仕様です。元のファイルは書き換わりません。

作業が終わったら、ウィンドウを閉じてください。裏の仕組みも自動で終了します。

6. うまくいかないとき（FAQ）

困りごと対処
ダブルクリックしても画面が開かない数十秒待ってから、もう一度ダブルクリックしてください。それでも開かない場合は、exe と同じ場所にできる data\logs フォルダの中のファイルを添えて、情報システム担当へ連絡してください。
文字をドラッグできないまず文字を 1 回クリックして選んでください（まわりに枠と丸い点が出ます）。橙色の点（アンカー）は仕様上動かせません。
保存したファイルが見つからない保存先はダウンロードフォルダです（例: C:\Users\<名前>\Downloads）。エクスプローラー左側の「ダウンロード」を開いてください。
保存先を選ぶ画面が出ない故障ではなく仕様です（6 章の 1 つ上の囲みを参照）。保存後にダウンロードフォルダから移動してください。
間違えて動かしすぎたCtrl+Z で 1 つずつ戻せます。まとめて戻すなら「このラベルをリセット」「このファイルをリセット」（4.4 節）。
同じファイルをもう一度直したい保存したファイル（ダウンロードフォルダの方）を開き直せば、続きから調整できます。
画面を閉じ忘れても大丈夫?大丈夫です。ウィンドウを閉じれば自動で終了します。万一の場合も約 60 秒で自動的に止まる仕組みです。
Edge が入っていないパソコンで使える?ふだんお使いのブラウザで開きます（見た目が少し変わりますが操作は同じです）。Windows 10 / 11 なら Edge は標準で入っています。

7. 補足: 開発者向け（通常の利用では読み飛ばしてください）

exe を使わずソースから直接起動する場合は、リポジトリの graph-editor/ で次を実行します。

python app.py

実行は Python 標準ライブラリのみで追加インストール不要です（requirements.txt の pyinstaller は exe ビルド時のみ）。exe のビルドは graph-editor\scripts\build.bat を ダブルクリックすると dist/LabelEditor.exe が生成されます。詳細は別冊 「SVG ラベル位置エディタ 配布・運用手順書」および「詳細設計書」を参照してください。
