このツールは、pie-chart が作った円グラフ SVG を読み込み、**ラベル（文字）と引出線（leader）をマウスでドラッグして位置を微調整**し、修正版 SVG を保存するためのものです。`LabelEditor.exe` をダブルクリックすると、Windows 標準の Microsoft Edge がアプリ窓として開いて編集できます（ターミナル操作は不要）。

# 0. はじめに — 前提と画面の見方

## 0.1 前提

- 必要なのは **`LabelEditor.exe` 1 ファイルだけ**です。好きな場所に置いてダブルクリックしてください（追加インストール不要。描画には Windows 標準の Microsoft Edge を使います）。
- 扱うファイルは pie-chart が生成した **円グラフの SVG ファイル**です。元のファイルは上書きされないので、安心して操作できます。
- 作業の流れは画面上部の **3 つのステップ**「1 ファイルを開く → 2 位置を調整 → 3 SVGを保存」の順に進むだけです。

## 0.2 画面の見方（編集中の画面全体）

![編集画面の全体。上=ステップバー、左=開いたファイルの一覧、中央=グラフ、右=選択中ラベルの設定](images/editor_main.png)

| 場所 | 名称 | 役割 |
|---|---|---|
| 最上部 | アプリバー | 開いているファイル名の表示と、元に戻す（Ctrl+Z）・やり直し（Ctrl+Y）ボタン |
| 上部 | ステップバー | 「1 ファイルを開く / 2 位置を調整 / 3 SVGを保存」。クリックで行き来できます |
| 左 | ファイル一覧 | 開いたファイルの切り替え。「ファイルを開く…」「このファイルをリセット」もここ |
| 中央 | キャンバス | グラフ本体。ラベルをドラッグして動かします。右下にズーム ± |
| 右 | 選択中のラベル | クリックで選んだラベルの設定（引出線・文字色・行数・長体など） |
| 最下部 | フッター | 「戻る」「次へ」ボタンと操作ヒント |

# 1. ステップ1: ファイルを開く

1. `LabelEditor.exe` をダブルクリックすると、「ファイルを開く」画面が表示されます。

![起動直後の「ファイルを開く」画面](images/open_screen.png)

2. **「ファイルを選択…」** をクリックして SVG ファイルを選びます（複数選択できます）。画面へ**ドラッグ＆ドロップ**でも開けます。
3. ファイルを開くと、自動的にステップ 2（編集画面）へ進みます。

# 2. ステップ2: ラベルと引出線を動かす

## 2.1 基本操作

- **ラベルの文字を掴んでドラッグ**すると動かせます。引出線は文字に追従して伸び縮みします。
- さらに細かく調整したいときは、ラベルをクリックして選択し、出てくる丸い点（ハンドル）をドラッグします。

![選択中ラベルのハンドル。緑=端点（文字側）、青=曲点（折れ目）、橙=アンカー（円側・固定）](images/handles_zoom.png)

| 色 | 名称 | 操作 |
|---|---|---|
| 🟢 緑 | 端点（文字側） | ドラッグで動かせます |
| 🔵 青 | 曲点（折れ目） | ドラッグで動かせます |
| 🟠 橙 | アンカー（円に接する根元） | **動かせません**（円グラフの切片に固定されています） |

> [!INFO] ラベルを円の外へ出すと引出線が自動で付き、円の中へ戻すと自動で消えます。手でハンドルを動かした引出線は、それ以降は自動調整されません（あなたの調整が優先されます）。

## 2.2 右パネルで見た目を整える

ラベルを選択すると、右側の「選択中のラベル」パネルで次を切り替えられます。

![右パネル「選択中のラベル」](images/panel_right.png)

- **引出線**: 表示 / 非表示。
- **曲げ点**: あり（L 字に折れる）/ なし（直線）。
- **文字色**: 黒 / 白。
- **行数**: 1 行（名前と「○○%」を 1 行にまとめる）/ 2 行。
- **長体（横圧縮）スライダ**: 文字を横方向に圧縮します（100〜70%）。名前部分だけを横に縮め、高さと「%」部分は変えません。

![長体 70% を適用した状態（同じラベルの比較用）](images/condense_zoom.png)

## 2.3 やり直したいとき

- **Ctrl + Z**: 元に戻す（アプリバーの ↩ ボタンでも可）。
- **Ctrl + Y**: やり直し（↪ ボタンでも可）。
- 右パネル下の **「このラベルをリセット」**: 選択中のラベルだけを開いた直後の状態へ戻します。
- 左下の **「このファイルをリセット」**: 表示中のファイル全体を開いた直後の状態へ戻します（確認ダイアログが出ます）。

## 2.4 キーボード操作まとめ

| キー | 動作 |
|---|---|
| 矢印キー | 選択中ラベルを 1px ずつ移動 |
| Shift + 矢印 | 10px ずつ移動 |
| Ctrl + Z / Ctrl + Y | 元に戻す / やり直し |
| Ctrl + O | ファイルを開く |
| Ctrl + S | 保存（ステップ 3 と同じ） |
| Escape | 選択を解除 |

# 3. ステップ3: SVG を保存する

1. 調整できたら「次へ」でステップ 3 へ進み、**「保存する」** をクリックします。

![「SVGを保存」画面](images/save_screen.png)

2. 修正版の SVG が **ダウンロードフォルダに保存されます**（保存先のフォルダは選択できません。これはリモートデスクトップ環境でも安定して動かすための仕様です）。
3. 元のファイルは上書きされません。保存時には編集用の補助要素（ハンドル等）を取り除いた、きれいな SVG が書き出されます。

> ヒント: 元データを直接書き換えるツールではありません。あくまで「出来上がった SVG の見た目を手直しする」ための道具です。

# 4. 困ったとき（FAQ）

| 症状 | 原因と対処 |
|---|---|
| ダブルクリックしても窓が開かない | exe と同じ場所にできる `data\logs\startup.log`（起動診断）と `data\logs\edge.log`（Edge 側）を開き、記載のエラーを確認してください。Microsoft Edge がインストールされていない端末では既定のブラウザで開きます。 |
| ラベルをドラッグできない | まずラベルの**文字**をクリックして選択してください（周りに点線の枠とハンドルが出ます）。橙のハンドル（アンカー）は仕様上動かせません。 |
| 保存したファイルが見つからない | 保存先は**ダウンロードフォルダ固定**です（例: `C:\Users\<名前>\Downloads`）。ブラウザのダウンロード通知からも開けます。 |
| 保存先を選ぶ画面が出ない | 仕様です（リモートデスクトップ環境での安定性のため）。保存後にダウンロードフォルダから任意の場所へ移動してください。 |
| 間違えてラベルを動かしすぎた | Ctrl+Z で 1 つずつ戻すか、右パネルの「このラベルをリセット」/ 左下の「このファイルをリセット」で開いた直後に戻せます。 |
| 窓を閉じ忘れたのにプロセスが残っていないか心配 | 窓を閉じれば自動終了します。万一通信が途絶えた場合も、約 60 秒で自動的に終了する仕組みです。 |
