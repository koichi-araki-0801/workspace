pie-chart は、「名前と数値」の一覧（例: 株式 18、債券 15、…）から、円グラフの画像ファイルを自動で作るツールです。ラベルの位置や引き出し線の形はすべて自動で決まるので、レイアウトの手作業は一切不要です。

本書は、**パソコンの専門知識がない方でもそのまま操作できる**ことを目指して書いています。1〜5 章の手順どおりに進めれば、配布された `dist-exe` フォルダだけで円グラフが作れます。プログラム開発環境（Node.js など）をお使いの方は 6 章「開発者向け補足」もご覧ください。ツールの内部構造を知りたいときは別冊「pie-chart 詳細設計書」をご覧ください。

# 0. はじめに

## 0.1 このツールで何ができるか

- 入力: 「名前」と「数値」の 2 列の表（Excel の 2 列、またはテキスト形式のデータ）。
- 出力: 円グラフの画像ファイル 1 枚（SVG 形式。ブラウザで開けます）。

![生成例（シンプル: 4 スライス）](images/sample_simple.png)

![生成例（高密度: 12 スライス。引出線・改行・自動調整が効いた状態）](images/sample_dense.png)

> [!INFO] 同じ入力からは**毎回まったく同じ画像**が作られます。「昨日と同じデータなのに絵が変わった」ことは起きない設計です。

## 0.2 用語表（本書で使う言葉の言い換え）

| 本書の言葉 | 意味 |
|---|---|
| SVG ファイル | このツールが作る画像ファイルです。ファイル名の末尾が `.svg` で、Edge などのブラウザで開いて表示・印刷できます。 |
| `dist-exe` フォルダ | 配布される一式のフォルダです。この中の `pie-chart.exe` が本体です。 |
| 黒い画面（コマンド プロンプト） | 文字で命令を入力する Windows の画面です。本書では「開き方」から説明します。難しい操作は「1 行貼り付けて Enter」だけです。 |
| コマンド | 黒い画面に貼り付ける 1 行の命令文です。本書の枠内の文をそのままコピーして使えます。 |
| サンプル | ツールに内蔵されているお試しデータです。自分のデータがなくても動作確認できます。 |
| 引出線 | 円グラフのラベルと切片を結ぶ線のことです。自動で引かれます。 |
| 範囲（Excel） | `A2:B11` のような Excel のセルの範囲指定です。 |

# 1. 準備 — 受け取ったフォルダを確認する

## 1.1 受け取るもの

システム担当者から **`dist-exe` フォルダ一式**を受け取ります。中身は次の 4 つです。

| 名前 | 役割 |
|---|---|
| `pie-chart.exe` | ツール本体です。 |
| `pie-chart-codesign.cer` | 安全確認用の証明書です（初回設定で使うことがあります。4 章）。 |
| `fonts` フォルダ | 画像に文字を埋め込むためのフォントです。 |
| `node_modules` フォルダ | 本体が使う部品です。 |

> [!WARN] **フォルダの中身は絶対にバラバラにしないでください。** `pie-chart.exe` だけを別の場所へコピーすると、文字が正しく埋め込まれなくなります。移動するときは `dist-exe` フォルダごと移動してください。

## 1.2 フォルダを置く

1. 受け取った `dist-exe` フォルダを、デスクトップなど分かりやすい場所に置きます。

## 1.3 操作用の黒い画面を開く

`pie-chart.exe` は**ダブルクリックしても画面が一瞬出て消えるだけ**です（故障ではありません）。操作は次の手順で開いた黒い画面から行います。

1. エクスプローラー（フォルダを見る画面）で `dist-exe` フォルダを開きます。
2. 画面上部の**アドレスバー**（フォルダの場所が文字で表示されている細長い欄）を 1 回クリックします。
3. 表示されていた文字が選択されたら、キーボードで `cmd` と入力します。
4. Enter キーを押します。
5. 黒い画面が開きます。左側に今のフォルダの場所（`...\dist-exe>`）が表示されていれば成功です。

> [!INFO] 以降の章のコマンドは、すべてこの黒い画面に**コピーして貼り付け → Enter** で実行します。貼り付けは黒い画面の上で右クリックするだけでできます。

# 2. まず 1 枚作ってみる（内蔵サンプル）

自分のデータを使う前に、内蔵サンプルで動作確認します。

1. 1.3 の手順で黒い画面を開きます。
2. 次の 1 行をコピーします。

```
pie-chart.exe one --sample asset_gbca_pdf_like --output-file test.svg
```

3. 黒い画面の上で右クリックして貼り付けます。
4. Enter キーを押します。
5. 画面に `C:\...\test.svg` のようなファイルの場所が 1 行表示されれば成功です。
6. エクスプローラーで `dist-exe` フォルダを見ると、`test.svg` というファイルが増えています。

## 2.1 できた画像を表示する

1. `test.svg` を右クリックします。
2. 「プログラムから開く」をポイントします。
3. 「Microsoft Edge」をクリックします。
4. ブラウザに円グラフが表示されます（印刷もこの画面からできます）。

> [!INFO] 内蔵サンプルの名前一覧は `pie-chart.exe list` を実行すると表示されます（全 83 種類）。

# 3. 自分のデータで作る

## 3.1 Excel の表から作る

Excel ファイルの「名前の列」と「数値の列」が**左右に隣り合っている**ことを確認してください（例: A 列に名前、B 列に数値）。

1. Excel ファイル（例: `データ.xlsx`）を `dist-exe` フォルダの中にコピーします。
2. Excel を開き、データが入っているシート名（例: `Sheet1`）と、データ行の範囲（例: 2 行目から 11 行目 → `A2:B11`）をメモします。
3. 1.3 の手順で黒い画面を開きます。
4. 次の 1 行をコピーし、`データ.xlsx`・`Sheet1`・`A2:B11` の 3 か所を自分の内容に書き換えます。

```
pie-chart.exe one --xlsx データ.xlsx --sheet Sheet1 --range A2:B11 --output-file グラフ.svg
```

5. 黒い画面に貼り付けて Enter キーを押します。
6. ファイルの場所が 1 行表示されれば成功です。`グラフ.svg` を 2.1 の手順で表示して確認します。

> [!WARN] 範囲指定の決まりが 3 つあります。
> - **見出し行は範囲に含めない**でください。1 行目に「区分」「比率」のような見出しがある場合、範囲は `A2:...` から始めます（含めると `Non-numeric value at row 1` というエラーになります）。
> - 範囲は**必ず 2 列**です（左=名前、右=数値）。3 列以上や 1 列だけはエラーになります。
> - 数値の列に文字が入っているとエラーになります（空行は自動で飛ばされます）。

> [!INFO] 数値は比率でも実額でもかまいません（合計が 100 になっている必要はありません）。また、行の並び順は気にしなくて大丈夫です。グラフでは自動的に大きい順に並び、「その他」は最後に回ります。

## 3.2 データを直接書いて作る（Excel を使わない場合）

名前と数値を次の形で 1 行に書いて渡すこともできます。

1. 次の 1 行をコピーし、名前と数値の部分を自分のデータに書き換えます。

```
pie-chart.exe one --data-json "[{""name"":""株式"",""value"":60},{""name"":""債券"",""value"":40}]" --output-file グラフ.svg
```

2. 黒い画面に貼り付けて Enter キーを押します。

> [!INFO] 黒い画面（cmd）では、データの中の `"` を `""` と 2 つ重ねて書く決まりがあります。上の例はそのまま書き換えて使える形にしてあります。件数が多い場合は、システム担当者に JSON ファイル（`--data-file` で読み込むファイル）の形で用意してもらうのが確実です: `pie-chart.exe one --data-file データ.json --output-file グラフ.svg`

## 3.3 たくさんのファイルをまとめて作る

JSON ファイルをフォルダにまとめて置くと、一括で SVG に変換できます。

1. `dist-exe` フォルダの中に `data` という名前のフォルダを作ります。
2. `data` フォルダに JSON ファイル（`〜.json`）を入れます。
3. 次の 1 行を黒い画面に貼り付けて Enter キーを押します。

```
pie-chart.exe batch --input-dir data --output-dir out
```

4. `out` フォルダに、JSON と同じ名前の SVG ファイルがまとめて作られます。

# 4. 初回だけの設定（警告が出るとき）

初めて `pie-chart.exe` を実行するとき、Windows が「WindowsによってPCが保護されました」という青い画面（SmartScreen）を出すことがあります。

- その場で 1 回だけ実行する場合: 「詳細情報」をクリックし、「実行」をクリックします。
- 警告を今後出さないようにする場合: **システム管理者に依頼**して、同梱の証明書 `pie-chart-codesign.cer` を信頼登録してもらいます（管理者権限が必要です）。管理者向けのコマンドは次の 2 行です。

```
certutil -addstore Root pie-chart-codesign.cer
certutil -addstore TrustedPublisher pie-chart-codesign.cer
```

# 5. うまくいかないとき（FAQ）

| 症状 | 原因と対処 |
|---|---|
| `pie-chart.exe` をダブルクリックしても黒い画面が一瞬出て消える | 故障ではありません。このツールは黒い画面から命令で動かす作りです。1.3 の手順で黒い画面を開き、2 章のコマンドを貼り付けてください。 |
| `'pie-chart.exe' は、内部コマンド…として認識されていません` と出る | 黒い画面が `dist-exe` フォルダ以外の場所で開いています。いったん黒い画面を閉じ、必ず `dist-exe` フォルダのアドレスバーから `cmd` で開き直してください（1.3）。 |
| 青い画面「WindowsによってPCが保護されました」が出る | 初回のみの安全確認です。「詳細情報」→「実行」の順にクリックしてください。恒久対応は 4 章の証明書登録です。 |
| `Non-numeric value at row 1` （または行番号つきの同様のエラー）が出る | Excel の範囲に見出し行が混ざっています。範囲をデータ行のみ（例: `A2:B11`）に直してください（3.1）。行番号は「範囲の中の何行目か」ではなく Excel の行番号です。その行の数値列に文字が入っていないかも確認してください。 |
| `Range must span exactly 2 columns ...` と出る | 範囲が 2 列（左=名前、右=数値）になっていません。`A2:B11` のように 2 列だけを指定してください（3.1）。 |
| `Sheet not found: ...` と出る | `--sheet` に指定したシート名が Excel ファイルにありません。エラーの `available: ...` に実際のシート名一覧が出るので、そこから選び直してください。 |
| `Unknown sample: ...` と出る | `--sample` の名前が違います。`pie-chart.exe list` で正しい名前を確認してください。 |
| `--output-file is required.` と出る | 出力ファイル名の指定が抜けています。コマンドの末尾に `--output-file グラフ.svg` を付けてください。 |
| できた SVG を開くと文字の形がおかしい / ファイルサイズがとても大きい | `pie-chart.exe` だけを別の場所へコピーして実行しています。`fonts` と `node_modules` が同じ場所に無いとフォントの埋め込みが働きません。`dist-exe` フォルダごとコピーし直し、フォルダの中で実行してください（1.1）。 |
| `msnodesqlv8 is not installed. ...` と出る（DB 読み込み） | データベース読み込み用の部品が入っていません。DB 入力（`--sql`）を使う場合のみ追加が必要です。システム担当者に「`dist-exe/node_modules` へ `msnodesqlv8` を追加してほしい」と依頼してください（6.4）。 |
| DB 接続に失敗する | 接続は Windows ログオンユーザーの権限で行われます（パスワード入力はありません）。実行している Windows ユーザーに対象データベースの参照権限があるか、`--db-server` / `--db-name` の指定が正しいかをシステム担当者に確認してください（6.4）。 |
| 黒い画面に赤やエラーらしき英語が出たが意味が分からない | エラー文の 1 行目をそのままコピーして、システム担当者へ連絡してください。本ツールはエラー時にファイルを壊すことはありません。 |

# 6. 開発者向け補足

ここから先は開発環境（Node.js / pnpm / npm）を使う方向けです。事務作業では読む必要はありません。

## 6.1 環境の読み分け

| 環境 | 見分け方 | 使うコマンド |
|---|---|---|
| 開発機（pnpm + Node 24 系） | リポジトリ全体を clone しており `pnpm -v` が通る | `pnpm --filter pie-chart run <script>`（または `pie-chart/` 内で `pnpm run <script>`） |
| 旧 Node 20 系の単独環境 | `pie-chart/` フォルダ単体で渡されており pnpm が無い | `pie-chart/` 内で `npm run <script>` |
| 非開発者の端末（Node 無し） | `dist-exe/` フォルダを受け取った | `pie-chart.exe <command>`（1〜5 章） |

以降のコマンド例は `npm run ...` で書きます。開発機では `pnpm --filter pie-chart run ...` に読み替えてください。

- セットアップと動作確認: `npm install` → `npm run check`（型チェック）→ `npm run batch`（全 83 サンプル一括生成。`SVG: 83/83 OK` が出れば正常）→ `npm run verify`（自動検証）。
- 旧 Node 20 系向けに `package.json` の `overrides` で **vite を `^6` に固定**しています（vite@8 / rolldown は Node 20.16 で EBADENGINE になるため）。pnpm はルートの `overrides` しか見ないので、開発機は最新 vite@8 のまま＝npm 経路だけ vite@6 へ切り替わります。vite/vitest はテスト専用で、`cli` / `batch` / `verify` / `build:exe` は tsx・esbuild 経由のため SVG 出力には影響しません。

## 6.2 CLI の使い方

CLI は `npm run cli -- <command>`（または直接 `tsx src/cli.ts <command>`）で実行します。exe 版（`pie-chart.exe <command>`）も引数はまったく同じです。コマンドは `list` / `one` / `batch` の 3 種です。

> [!INFO] `npm run cli --` の `--` は「これ以降の引数を npm ではなくスクリプト本体へ渡す」という npm の決まり文句です。忘れると引数が無視されます。

| コマンド | 用途 |
|---|---|
| `list` | 利用可能なサンプル名を一覧表示 |
| `one` | 1 枚の SVG を生成（入力 1 系統 + `--output-file` 必須） |
| `batch` | 複数 SVG を一括生成（既定で全サンプル。`--samples a,b,c` で絞り込み、`--input-dir <dir>` で JSON フォルダ一括） |

```
npm run cli -- list
npm run cli -- one --sample asset_gbca_pdf_like --output-file out/test.svg
npm run cli -- one --data-file data/example.json --output-file out/test.svg
npm run cli -- one --data-json '[{"name":"A","value":60},{"name":"B","value":40}]' --output-file out/test.svg
npm run cli -- one --xlsx data.xlsx --sheet Sheet1 --range A2:B11 --output-file out/test.svg
npm run cli -- one --sql "SELECT 区分, 比率 FROM dbo.資産配分" --db-name usrap --output-file out/test.svg
npm run cli -- batch --output-dir out/svg
npm run cli -- batch --input-dir data --output-dir out/svg
```

`one` の入力は `--sample` / `--data-file` / `--data-json` / `--xlsx + --sheet + --range` / `--sql` の**いずれか 1 つ**です（複数指定はエラー）。描画オプションとして `--font-weight <400|700>`（ウェイト切替）と `--stroke-ratio <num>`（faux-bold の stroke 量。既定 0=無効）があります。

## 6.3 Excel 入力の決まり

- `--range` は **2 列固定**（左=name、右=value）。3 列以上 / 1 列はエラーです。
- **ヘッダ行は指定しません**（データ行のみ）。先頭行が「区分」「比率」のような文字列だと `Non-numeric value at row N` で落ちます。
- 空行はスキップされ、name 空欄や value の数値変換不可は明示エラーになります。
- 数式セルは結果値で取り込み、リッチテキスト / ハイパーリンクも展開して取り込みます。
- `exceljs` 依存は `src/input/load.ts` の xlsx 節に隔離しています（`parseRange` / `loadXlsxItems`）。

## 6.4 DB（SQL Server）入力の決まり

`--sql <SELECT文>` で SQL Server の結果セットから直接取り込みます。接続は **Windows 統合認証**固定で、資格情報は持ちません（いま Windows にログインしているユーザーの権限でつながります）。

- **単一の SELECT 文のみ**です。複文（文中 `;`）・非 SELECT（UPDATE/DELETE 等）は拒否されます。
- 列解決は Excel と同じ考え方です。`--name-col` / `--value-col` を**両方**指定すれば列名で、無指定なら結果セットの**先頭 2 列**を name/value とします（3 列以上で未指定はあいまいエラー）。
- 接続先は `--db-server`（既定 env `DB_SERVER` / `localhost`）・`--db-name`（既定 env `DB_NAME`）です。ODBC ドライバは既定 `ODBC Driver 17 for SQL Server`（env `DB_ODBC_DRIVER` で変更可）。
- ネイティブドライバ `msnodesqlv8` は `optionalDependencies` です。**遅延 require** のため未導入でも他入力（sample/json/xlsx）と `tsc` は動きます。DB 入力を使うときだけ導入してください。接続・SQL 依存は `src/input/db.ts` に隔離しています（`buildConnectionString` / `assertSelectOnly` / `rowsToItems` / `loadDbItems`）。
- exe 配布版で DB 入力を使う場合は `dist-exe/node_modules` へ `msnodesqlv8` を追加します（描画・Excel 入力は追加不要で動きます）。

## 6.5 全件生成とビューア確認

- `npm run batch` … 全 83 サンプルを `out/svg_js/` に出力し、`out/compare.html`（A4 想定・1 ページ 12 件のページ送り）を更新します。ブラウザで開いて目視確認できます。
- `npm run verify` … 生成済み SVG のラベル数・bbox オーバーラップ・円内侵入・引出線交差・viewBox はみ出し・引出線屈曲数を自動検証します（対象ディレクトリは引数指定可。既定は `out/svg_js`）。
- `npm run batch:diff` … `out/svg_js` と `out/_baseline` を SHA256 で全件比較します（リファクタ・コメント変更の出力バイト不変の確認。検証手順の正典は `pie-chart/README.md` の「検証」節）。

![compare.html ビューア（A4 プレビュー・1 ページ 12 件）](images/viewer.png)

> [!INFO] `verify` は生成済み SVG を読むため、先に `batch` を実行しておいてください。現況（2026-07-21 再計測）は **5/83 サンプルで警告（計 8 件）**ですが、これらは既知の WARN（長い名前の viewBox はみ出し。`pie-chart/README.md` に記録済み）で、ERROR 級（引出線の交差・円内貫通）は 0 件です。既知の件数から**増えていなければ正常**と判断してください。

## 6.6 exe のビルドと配布

Node も tsx も無い端末へ配る実行ファイルを生成します。入口は 2 つで、依存の入れ方が異なります。**配布物は `dist-exe/` フォルダ一式**です。

- **`scripts/build-exe.bat`（ダブルクリック / 旧 Node20 系の単独環境向け）**: 同名の `build-exe.ps1` を起動し、ビルド前に `node_modules` / `package-lock.json` を消して **`npm install` をクリーン実行**してから exe を作ります。「このフォルダだけ」で完結します。
- **`npm run build:exe` / `pnpm run build:exe`（= `node scripts/build-exe.mjs`、開発機向け）**: install はせず、既存の `node_modules` でビルドのみ行います（pnpm ワークスペースの依存解決を保つため）。

```
dist-exe/
├── pie-chart.exe          — Node SEA 実行体（cli を esbuild で単一 CJS 化して inject）
├── pie-chart-codesign.cer — 自己署名の公開証明書（配布先で信頼登録すると署名が Valid に）
├── fonts/                 — 埋込元の woff2（BIZ UDPGothic 400/700）
└── node_modules/          — subset-font + 依存（harfbuzzjs wasm 等）
```

- フォントと `subset-font` は exe に埋め込まず**外部参照**します（`fonts/` と `node_modules` を exe と同じ場所に置く）。**フォルダごと**渡してください。exe 単体をコピーして渡すとフォント埋込が効かなくなります。
- ビルド時（Windows）に `scripts/sign-exe.ps1` が exe を**自己署名**で SHA256 署名し、公開証明書（.cer）を書き出します。配布先での信頼登録は 4 章のとおりです。
- exe 版の出力は tsx 版と **byte-identical** です。
